# 원본: GPT 대화 — 대학 수준 게임기획 독학 커리큘럼 (2026-10-22, 사용자 제공)

사용자가 관제 세션에 붙여 준 GPT 답변 두 개를 그대로 옮긴 것이다. 링크의 utm 매개변수만 남겨 두었다. 이 파일은 고치지 않는다.

## 답변 1 — 공개 대학 강의

대학교에 가지 않고도 대학 수준의 게임기획 커리큘럼을 상당 부분 독학할 수 있어. 특히 MIT는 실제 학부 강의의 영상·읽기자료·과제·학생 결과물까지 공개하고 있어서, 강의만 듣는 게 아니라 대학생들이 수행한 과정을 따라갈 수 있어.

국내 KOCW는 한국어 강의와 강의자료 확보에 유리하고, MIT OpenCourseWare는 교육과정의 완성도, 과제, 평가 기준을 확보하는 데 유리해.

### 1. 가장 추천하는 공개 대학 강의

1. MIT — Introduction to Game Design Methods (CMS.301, 2016 봄, 가장 추천): 게임 분석부터 디자인 문서 작성, 프로토타입 제작, 플레이테스트까지 연속된 과제. 과제 PDF 8종, 과제 예시, 읽기자료, 일부 슬라이드.
   - 과제: https://ocw.mit.edu/courses/cms-301-introduction-to-game-design-methods-spring-2016/pages/assignments/
   - 홈: https://ocw.mit.edu/courses/cms-301-introduction-to-game-design-methods-spring-2016/
2. MIT — Game Design (CMS.608, 2014 봄): 게임 메커니즘, 의미 있는 선택, MDA, 규칙 변경, 플레이테스트, 플레이어 경험. 강의영상, 과제 PDF, 학생 제작 게임.
   - 홈: https://ocw.mit.edu/courses/cms-608-game-design-spring-2014/
   - 과제와 학생 작품: https://ocw.mit.edu/courses/cms-608-game-design-spring-2014/pages/assignments-and-student-work/
3. 한성대 — 디지털 스토리텔링 실습 (2025-1, KOCW): 시스템 기획, 스토리텔링, 방 탈출, 미션 설계, 레벨 디자인. https://www.kocw.net/home/search/kemView.do?kemId=1526218
4. 중앙대 — 게임아트와 내러티브 (KOCW): 재미요소 분석, 발상법, 콘셉트, 시스템, 레벨, 도전과 보상. https://www.kocw.net/home/search/kemView.do?kemId=1178194

### 2. K-MOOC

- 게임컨셉디자인 — 계명대 (현재 모집 중): 15주, 영상 약 25시간, 한국어, 이수증. 장르 분석, 메커니즘, 세계관, 캐릭터, 레벨, UI/UX, 몰입, 프로토타입. 최종평가는 게임 콘셉트 기획서. 수강신청 2026.9.18~12.31, 운영 2026.10.18~2027.1.31. https://www.kmooc.kr/view/course/detail/21313
- 게임기획실무 — K-MOOC (과거 운영, 2025 종료, 청강 가능 여부 확인 필요): 13주, 약 20시간. 디자인 원리, MDA, 핵심 메커니즘, 밸런싱, 인터페이스, 흥미곡선, GDD. 중간·기말·분석 보고서. https://www.kmooc.kr/view/course/detail/17793

### 3. MIT — Creating Video Games (CMS.611J, 2014 가을, 27회, 영어)

팀 협업, 애자일, 사용자 테스트, 데이터 분석까지. 2인 게임개발과 특히 잘 맞음.
- 전체: https://ocw.mit.edu/courses/cms-611j-creating-video-games-fall-2014/
- 강의영상: …/pages/lecture-videos/ · 슬라이드: …/resources/lecture-notes/ · 과제 PDF: …/resources/projects/ · 진도표: …/pages/calendar/ · 다운로드: …/download/
- 실제 자료: Focus Test Script, Sample Focus Test Document, Focus Test Summary, Sample Project Backlog, Project 4: Small Game Project.
- 평가 기준: 기능·완성도 20%, 반복적 디자인 과정 20%, 프로젝트 관리 20%, 개인 포스트모템 20%, 팀 포스트모템 발표 20%. 게임이 돌아가는 것은 20%이고 나머지 80%는 설계 반복·협업 과정·회고.

### 4. 에듀코카 (한국콘텐츠진흥원)

게임기획 직무강의(로그인 필요): 게임 시스템 기획, 수치 레벨디자인 기초(엑셀), 게임 공간 레벨디자인, 레벨디자인 기초 원리(RPG). 테마과정: https://edu.kocca.kr/edu/onlineEdu/themeLecture/view.do?menuNo=500157&pId=90&pageIndex=1
로그인 없이: 장르에 대한 이해(pSeq=1044), 실시간 게임의 이해 — 이스(1045), 턴방식 게임의 이해 — 히어로즈 오브 마이트 앤 매직(1046), 인디게임 결과물로 이어지는 제작(794). 주소 형식: https://edu.kocca.kr/edu/onlineEdu/openLecture/view.do?menuNo=500085&pSeq=<번호>

### 5. 무료 교재

Ian Schreiber — Game Design Concepts (https://gamedesignconcepts.wordpress.com/), Game Balance Concepts (https://gamebalanceconcepts.wordpress.com/, 10주).

### 6. 독학 순서

1단계 기초: K-MOOC 게임컨셉디자인 + MIT CMS.608. 2단계 설계 방법: MIT CMS.301 + 에듀코카 시스템 기획·수치 레벨디자인. 3단계 제작 실습: MIT CMS.611J.
결론: K-MOOC 게임컨셉디자인으로 이론 뼈대, CMS.301 과제와 CMS.611J 평가 방식을 가져오는 조합.

## 답변 2 — 3주 속성 1회독 + 시간 제한 없는 2회독

1회독은 3주 동안 교육과정 전체 구조를 파악, 2회독은 시간 제한 없이 실제 대학 과제를 수행. 1회독에서 완강은 목표가 아니다.

### 1회독 — 3주

| 기간 | 범위 | 자료 |
|---|---|---|
| 1주차 | 디자인 원리, 메커니즘, 플레이어 경험, 게임 분석 | MIT CMS.608 + K-MOOC 게임컨셉디자인 |
| 2주차 | 시스템 기획, 레벨디자인, UI/UX, 밸런싱, 기획문서, 프로토타입 | MIT CMS.301 + 에듀코카 |
| 3주차 | 플레이테스트, 설계 반복, 제작 프로세스, 팀 협업, 프로젝트 평가 | MIT CMS.301 + CMS.611J |

공식 강의계획서와 과제 안내 중심으로 읽고 중요한 강의만 선택 수강. 3주차 종료 조건은 "잘하게 되는 것"이 아니라 대학이 무엇을 가르치고 과제로 요구하고 평가하는지 전체 지도를 갖추는 것.

### 2회독 — 영역과 통과 기준 중심

1. 게임디자인 이론: CMS.608 진도, 읽기자료, 공식 과제 1~3.
2. 분석과 설계 방법론: CMS.301 공식 과제 1~4.
3. 시스템·레벨·밸런스: K-MOOC 게임컨셉디자인, 에듀코카, CMS.301 GDD·프로토타입 과제.
4. 플레이테스트와 개선: CMS.301 플레이테스트 과제와 최종 탐구 프로젝트, 실제 플레이어 모집.
5. 실전 제작: CMS.611J 강의·프로젝트 요구사항, 협업·제작·테스트·회고.

다음 단계로 넘어가는 기준: 실제 대학 강의를 학습했는가 / 공식 과제를 수행했는가 / 새 사례에 적용할 수 있는가 / 외부 피드백·테스트로 자기 판단을 검토했는가.

주의: 2회독은 1회독의 반복이 아니다. K-MOOC 게임컨셉디자인은 2027-01-31까지만 열려 있다(MIT OCW는 기한 없음). 개발을 멈추고 수업만 듣기보다 대학 과제와 실제 개발 프로젝트를 병행. 독학의 가장 큰 결손은 교수 평가와 동료 비평 — MIT 학생 과제 예시와 실제 사용자 테스트로 보완.
