## 아안 (innollia)

### 본문
- 루프: 매 스테이지 클리어마다 용사의 검이 한단계 길어지고 스테이지가 한단계 길어짐.
- 스토리: 용사는 스테이지라는 고난과 역경을 헤쳐내고 계속해서 용을 죽이러 도전함.
- 메커니즘: 항아리게임의 메커니즘을 비틀어서 점점 길어지는 막대로 스테이지를 클리어하기. 각 길이(스테이지)마다 맵은 복리로 길어짐.
- 맵설계: 하나의 맵에 막대의 길이마다 클리어 루트가 달라져서 맵설계를 겁나 빡세게 한게 보임. 처음 길이에서 저기로 가면 뭐가 나올까 의문을 던지게 하고 두번째 길이에서 이 의문을 회수함. / 조사를 덜해서 설명할게 없네
- 메타: 아마 기획단계부터 2차창작 유저, 스피드런 유저들을 고려해서 게임의 스토리와 요소들을 설계했음. 실제로 2차창작, 스피드런계에서 유행을 타서 성공적.

### 포스트잇 (스크린샷 흐름 순서)
- 진부한 대장장이 NPC 말고 모험가 하나 붙여줬음
- 튜토리얼로서 우클릭 하나만으로 언덕 등반하는 법을 가르침
- 짧은 검으로는 못 올라가는 장소가 있음을 보여줌. 복선1
- 새로운 요소: 세이브포인트 / 맵에 텍스트를 그대로 붙이는 기법이 계속해서 쓰임
- 언덕 복습하기
- 검을 뒤로 끌고다니기만 하질 않고 앞으로 들고다니는 행위를 새롭게 학습
- 좁은 공간에서 거의 낄듯이 공간을 지나가는 경험. 복선2
- 칼이 길어서 천장에 낄 수 있음을 알림
- 하나의 스테이지를 여러 방식으로 클리어하게 만들기
- 같은 맵인데 칼만 길어졌음. 그렇다면? 복선 1, 위쪽 길을 갈 수 있게 됨을 유저가 유추할 수 있음 / 복선 2, 아래쪽 길은 갈 수 없게 됨을 유저가 유추할 수 있음
- 점프?를 학습시킴
- 스피드런 유저들에 대한 적극적인 지원을 해서 게임 홍보를 노림 (스피드런 설정 화면)
- 깨알 버전명 표시. (메뉴 화면)
- 플레이타임과 스테이지 수 표기 / 스테이지를 stage가 아니라 게임 컨셉에 맞게 length로 사용 / 게임 데모버전에서 테스트용으로 띄워둔 것 같음
- 직관적으로 주인공이 있는 위치 알리기. 좌측 벽, 우측 NPC, 주인공 바닥 반짝임, 키바인드 설명.
- 지나가면서 NPC가 말해줘서 저절로 읽고 가게 됨 / 쉬운 단어와 짧은 글이라 지나가는 찰나에 자연스레 읽힘
- 바닥에 칼이 끌리는 상황을 칼의 떨림과 파티클로 피드백
- 2차창작을 공략하는 설정 / 직진공 철벽수 / 덩치 차이 / 인외와의 사랑 / (농담 한 줄)
- 눈매 찢어진 것 좀 봐. 모에하잖아 (용)
- 메뉴 묶음: Pause Menu → Controls / Camera & Audio / Speedrun / Credits 화면 캡처

## 규민 (파이)

소제목: 접근성 / 게임 속 요소 / 시스템 / 사운드 / 상호작용

- 게임 시작 화면 간단하게 게임명을 보여줌
- 시작하고 아무것도 모르는 상태로 시작하지만 필요한 기능이 생길 때마다 알려줌
- 처음 보자마자 바로 칼 꽂았는데 누가봐도 의도를 알 수 있는 직관적인 그래픽
- 죽고 부활할 때마다 npc들의 대사가 바뀜
- 인테리어로 귀여운 고양이를 둠
- 체크 포인트 기능을 통해 불필요한 반복 요소 삭제 및 혹시 모를 끼임 등이 일어날 시 복구 가능하게 만듬 (게임하다 한 번 낀 적 있음)
- 가서 칼 꽂을 때마다 스테이지가 추가되서 새로운 맛을 보여줌. 이미 깬 스테이지도 칼의 길이가 늘어나며 새롭게 길이 바뀌거나 난이도가 바뀜. 반복 지루함 완화+플탐 뻥튀기
- 편의성 측면에선 설정에서 바로 칼 길이를 스킵할 수 있음
- (사운드) 캐릭터가 칼을 활용해 일정 각도(추측) 이상 올라갔을때 효과음과 모습이 바껴 그냥 검만 휙휙 될 수 있는 게임의 사운드를 적절하게 채우는 것같음
- (사운드) 위에 있다고 계속 핫 핫 대는 게 아닌 사운드 조건을 명확하게 했음. 작업하며 게임 켜놓느라 배경음악 계속 들리는데 무난하게 잘 만든 듯
- (사운드) 게임 내 소리가 나는 조건 > 검이 땅에 닿을 때, 캐릭터가 힘 줄 때, 배경음악 / 특수 상황 용이 불 뿜을 때, npc가 말할 때
- (상호작용) 클릭하면 바로 실행이 아닌 색깔이 바뀜
- (상호작용) 옆으로 지나가며 새로운 창이 나옴. 이를 통해 확실하게 입력했단 걸 쉽게 알려줌
- (상호작용) 이상한 곳 못 가게 투명 벽으로 막아둠
