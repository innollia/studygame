# 매니저 운영 규칙 (v1, 2026-10-22)

research/1~7을 읽고 매니저(오케스트레이터)가 지킬 규칙만 뽑았다. 근거와 출처는 각 research 파일에 있다. 숫자(분, 개수)는 연구가 정한 최적값이 아니라 시작값이고, 2주마다 실제 기록을 보고 고친다.

## 1. 일정 (research/2)
- 잼 기간(10/23~27, 10/29~11/1)은 새 강의 0분. 잼 날 학습은 "오늘 내린 설계 결정 1줄 + 이유"(3분)뿐이다.
- 복기 날: 10/28은 60분 복기(templates/jam-postmortem.md), 11/1은 제출과 겹치므로 15분 짧은 복기만 하고 나머지는 11/2에 한다.
- 1회독 D1~D21은 11/3(화)~11/24(화). 11/6(금)은 쉬는 날이라 의무가 0분이다. 11/25~29는 보강 칸, 11/30은 월간 리뷰.
- 학교 날 시간(사용자 확인, 2026-10-22):
  - 학교 안: 아안은 여유 120분. 학교 과제와 수행평가가 먼저이고, 남으면 그날 공부 자료를 미리 읽거나 자기 게임을 기획한다. 파이는 유튜브(깊게 1편 + 훑기 1~2편, 시작값 45분).
  - 집에 와서 잘 때까지: 둘이 함께 390분(6시간 30분). 시작값 배분은 체크인 10 / 공부 75 / 휴식 15 / 제작(핸섬가이즈 · Flesh Pit) 180 / 서로 플레이·검토 30 / 식사·휴식·버퍼 80.
  - 잼 날에는 공부 0분이고 제작이 약 300분이다. 주말 공부는 90분이다.
  - 390분을 꽉 채우지 않는다. 학교 마감이 생기면 버퍼 → 제작 → 공부(최소판 30분) 순서로 줄인다.
- 밀린 회차를 다음 날에 얹지 않는다. 한 회차가 밀리면 보강 칸으로 보내고, 두 회차 이상 밀리면 종료일을 늦춘다.
- 일요일(11/8, 11/15, 11/22) 공부 끝 10분에 주간 리뷰(templates/weekly-review.md)를 한다.
- 진도는 "정상 / 최소판 / 휴식"으로 구분해서 기록하고, 예상 시간과 실제 시간을 남긴다. 연속 기록으로 압박하지 않는다.

## 2. 학습 설계 (research/1)
- 모든 공부는 2분 인출로 시작한다. 자료를 열기 전에 지난 개념 하나를 자료 없이 말하고 예시를 하나 댄다. 그다음 원문과 맞춰 보고 고친다.
- 학습했다는 판단은 "이해한 느낌"이 아니라 "이틀 뒤 새 게임에 적용할 수 있는가"로 한다. 영상 개수, 플레이 시간은 노출량이지 학습 성과가 아니다.
- 한 회차에는 중심 개념 하나, 새 용어는 최대 3개만 다룬다.
- 파이는 예시를 보고 → 반쯤 채운 양식 → 혼자 분석하는 순서로 지원을 줄여 간다. 아안은 백지를 유지하고, 주장마다 근거·반례·다른 설명을 붙이게 한다.
- 분석할 때는 서로의 글을 보지 않고 먼저 쓴다. 비교는 그다음에 한다.
- 학습 스타일("청각형이라 영상만") 같은 분류는 쓰지 않는다. 근거가 약하다.

## 3. 숙제·피드백·평가 (research/3)
- 숙제 카드(templates/homework-card.md)에는 목표 1개, 분량(최소판 포함), 마감, 완료 기준 3개, 제출 위치를 쓴다.
- 분석 루브릭(templates/rubric.md)은 5기준 × 3단계(0 보완 / 1 도달 / 2 심화)다. 미리 공지하지 않은 기준으로 소급 감점하지 않는다. 학습자끼리 점수 경쟁을 시키지 않는다.
- 피드백 카드는 사람마다 강점 1개, 필수 수정 1개, 다음 한 걸음 1개(5~10분 안에 끝나고 확인할 수 있는 행동)로 쓴다. 나머지 개선점은 "보류"로 따로 적는다.
- 다음 회차를 시작할 때 지난 피드백을 반영했는지 확인해서 피드백 고리를 닫는다.
- 매니저도 추측을 사실처럼 쓰지 않는다. 피드백 안의 일반화에도 근거를 붙이거나 "(추측)"이라고 적는다.
- 아안의 스승 역할과 채점은 분리한다. 루브릭 적용은 매니저가 두 사람에게 같은 기준으로 한다.

## 4. 게임 분석 (research/4)
- 회차마다 관점(렌즈) 하나만 정한다. 보드의 5칸(루프 / 스토리 / 메커니즘 / 맵설계 / 메타)은 유지하되, 그날 렌즈와 상관없는 칸은 비워도 된다.
- 기록 단위는 장면 → 관찰 → 가설 → 다른 설명 → 확인 방법이다. 표시는 [봤음] [느꼈음] [추측] [외부 근거] [미확인]으로 나눈다.
- 근거의 등급: ① 직접 플레이·캡처 ② 제작자 공식 자료 ③ 외부 리뷰·반응 ④ 분석자 추정.
- 10/22 Deepest Sword 분석은 A0(기준선)이다. 1회독 분석 회차 A1~A6은 아래 계획을 따른다.

## 5. 유튜브 (파이, research/5)
- 하루 기본은 깊게 보기 1편 + 훑어보기 1~2편이다. 깊게 본 영상만 카드(templates/youtube-card.md)를 쓴다.
- 축이 되는 채널은 GMTK, Design Doc, NNgroup이다. 기초 보완은 얄팍한 코딩사전(Git)과 엔진 채널 하나(엔진은 하나만 고른다)로 한다. 뉴스 채널(코딩애플, AI Explained)은 훑어보기용이다.
- 잼 날에는 막힌 문제를 푸는 5~15분 영상만 본다. 쉬는 날은 의무가 없다.
- 아안은 주 2회 파이의 카드 하나를 골라 "근거 장면이 뭐야?"를 3분 동안 묻는다.
