# 피그잼 읽는 법 (매니저용)

보드가 커져도 전체를 읽지 않는다. **목록(지문)만 보고, 바뀐 섹션만 읽고, 읽은 것은 저장소에 남긴다.**

## 약속 (두 사람에게)
- 분석 회차마다 **새 섹션**을 만들고 이름을 `A1 · 11/05 · 게임이름`처럼 짓는다. 한 섹션에 한 회차만 둔다.
- 끝난 회차 섹션은 그대로 두어도 된다. 보드가 무거워지면 다른 페이지(보관)로 옮긴다. 매니저는 현재 페이지만 읽는다.

## 순서 (매니저)
1. 브라우저에서 보드를 열고 다 뜰 때까지 기다린다. 캔버스를 한 번 클릭하면 `figma` 전역이 준비된다.
2. `python tools/figjam_save.py --known` 결과를 `tools/figjam_extract.js`의 KNOWN에 넣고 `MODE="list"`로 실행한다. 섹션마다 이름, 글 개수, 글자 수, 해시, new/changed/same만 나온다(1~2KB).
3. 공부와 관련된 섹션 중 new/changed인 것의 id만 ONLY에 넣고 `MODE="read"`로 실행한다.
4. 결과 JSON을 임시 파일로 저장한 뒤 `python tools/figjam_save.py <파일>`을 실행한다. `docs/figjam/`에 섹션별 md가 생기고, `data/figjam-index.json`이 갱신된다. 작성자 이름은 aliases로 바뀌어 실명이 남지 않는다.
5. 피드백은 `docs/figjam/`의 md를 보고 쓴다. 같은 섹션을 다시 읽지 않는다.

## 읽지 않는 것
- 제작·운영 섹션(일정, 작명판, 게임 아이디어, 수익 분배 등 섹션 밖 도형)은 공부 피드백에 필요할 때만 읽고, 저장소에 저장하지 않는다. 저장소는 파이와 공유된다.

## 게임 아이디어 자동 분류
- "게임 아이디어 판"에 스티키를 올리면 하루 2번(13:00, 22:00) Jev가 분류해 옮긴다. 작업 스케줄러 `gamedesign-idea-sort` → `tools/idea_sorter.py`.
- 섹션은 성숙도: **쓸만한 아이디어**(핵심 동작 + 목표·변주·성장까지 있음) / **게임 아이디어 조각**. 색은 플랫폼: 노랑 인디, 빨강 로블록스, 파랑 모바일, 회색 어디든(여러 곳 또는 무관).
- 다른 아이디어에 단 반응 스티키는 바로 위 아이디어에 붙여 같이 옮기고, 그림 프롬프트는 판에 그대로 둔다.
- 질문 문구는 `tools/idea_sort.py`의 QUESTIONS, 결정 규칙은 decide(), 보드 조작은 `tools/figjam_ideas.js`.
- 봇 전용 크롬 프로필(`%LOCALAPPDATA%\gamedesign-idea-bot`)을 실행 때만 켰다 끈다. 사용자 크롬은 쓰지 않는다. Figma 로그인이 풀리면 `python tools/idea_sorter.py --login`.
- 기록: `data/idea-sorter.log`(git 제외, 스티키 원문 없음).
