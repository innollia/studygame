# 핸섬가이즈 아트스타일: 상남자 낙서

말랑하고 이상하게 생긴 낙서 생물이 돌 같은 턱과 근육을 달고 진지한 얼굴을 한다. 웃기는 이유는 본인은 진지하기 때문이다.

출발점은 hwapongstuy 레포의 `rain_world_graffiti` 화풍이다. 원본 낙서 모음은 [pimgit0/Rain-World-Images › Graffiti Drawings](https://github.com/pimgit0/Rain-World-Images/tree/main/Graffiti%20Drawings)에 있고, 이미지는 링크로만 남긴다.

## 쓰는 것
- 평평한 단색 면. 그라데이션, 입체 음영, 질감을 쓰지 않는다.
- 굵기가 일정한 검은 마커 선을 쓰되 손떨림과 삐뚤어진 비례가 남는다.
- 색은 정해진 3색만 쓴다: 검정 `#111111`, 크림 `#F3E9D2`, 빨강 `#E0301E`.
- 배경 없이 형상 하나만 두고, 필요하면 단색 면 하나를 깐다.
- 디테일은 턱, 눈썹, 근육선에만 몰고 나머지는 과감하게 뺀다.
- 몸은 동글동글 말랑하게 그리고, 턱·어깨·가슴만 각지고 돌처럼 단단하게 그린다.
- 표정은 무표정하고 진지하게 둔다. 웃지 않는다.

## 안 쓰는 것
- 흘러내리는 페인트, 스프레이 얼룩, 벽 질감
- 해골 얼굴, 여러 개 달린 눈, 이빨만 늘어선 얼굴처럼 원본에서 바로 떠오르는 얼굴
- Rain World의 기호, 캐릭터, 게임 속 장소
- 멋있는 근육남 일러스트, 매끈한 기업 마스코트, 귀여운 캐릭터
- 프롬프트에 작가 이름이나 게임 이름을 넣는 것
