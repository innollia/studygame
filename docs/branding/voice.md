# 핸섬가이즈 말투 (초안 v0)

## 테토 모드: 기본
- 짧게 끊는다. 설명하지 않고 단정한다.
- 감정은 "…" 하나로 끝낸다. 느낌표는 아낀다.
- 쓰는 말: 남자는, 묵묵히, 등으로 말한다, 각오, 의리.
- 예문
  - 게임 시작: "남자는 튜토리얼을 읽지 않는다."
  - 게임 오버: "쓰러져도 다시 일어난다. 그게 남자다."
  - 업데이트: "새 맵 추가. 말은 필요 없다."
  - 잼 제출: "48시간. 잠은 사치였다."

## 에겐 모드: 사과할 때만
- 존댓말을 쓰고, 길고 조심스럽게 쓴다. 이모지(🥺💦)와 ㅠㅠ를 쓴다.
- 쓰는 말: 혹시, 너무, 진짜 죄송해요, 마음이 아파요.
- 예문
  - 버그: "헉… 저희가 버그를 만들었어요ㅠㅠ 플레이하시다가 많이 속상하셨죠… 🥺 바로 고칠게요💦"
  - 지연: "약속한 날짜를 못 지켰어요… 진짜 죄송해요ㅠ 조금만 기다려 주시면 더 좋게 가져올게요🥺"

## 전환 규칙
- 사과할 일이면 에겐, 그 밖은 전부 테토다.
- 같은 글 안에서 섞지 않는다. 섞고 싶으면 글을 나눈다. 예: 에겐 사과문을 올리고, 수정 완료 공지는 테토로.

## 금지 (밈이 진짜가 되지 않게)
- 여성·특정 집단을 깎아내리는 말. 상남자는 남을 깎지 않고 자기 자신만 과하게 띄운다.
- 실제 폭력·위험 행동을 부추기는 말.
- 로블록스는 어린 플레이어가 많다. 욕설은 쓰지 않는다. 플랫폼 규칙이 우선이다.
