# 아안(innollia) 백지 분석 가이드

> 이 문서는 빈칸을 순서대로 채우는 학습지가 아닙니다. 백지에 글·화살표·도식·포스트잇을 **자유로운 순서와 형식**으로 쓰되, 다 쓴 뒤 아래 **제출 기준**이 들어 있는지 점검하는 기준표입니다. 시간(분)과 항목 개수는 모두 **시작값**입니다.

## 0. 분석 전 2분 인출 (시작값: 2분)

## 1. 백지 맨 위 헤더 한 줄
백지를 열고 맨 위에 아래 한 줄만 적은 뒤, 본문은 순서·분량·칸 수 제한 없이 자유롭게 구성합니다.

```text
[회차 / 날짜 / 게임 / 플레이 00분 / 렌즈: ___]
```

---

## 2. 제출 기준 (순서·형식 자유, 개수·분량은 시작값)
글의 어디에 어떤 모양으로 들어가든 아래 항목만 충족하면 됩니다.

- [ ] **핵심 주장 1개 (시작값)**: `"이 게임은 ___라는 장치로 ___라는 플레이 변화를 만든다."` (확인되지 않은 개발자 의도라고 단정하지 말 것)
- [ ] **근거 최소 3개 (시작값)**: 직접 플레이하며 잡은 스크린샷, 발생 시각, 상태 변화, 소리 조건 등. (독립된 장면 3개가 안 나오면 **같은 장면의 변형 2회 + 다른 장면 1회**로 적고 표시)
- [ ] **인과 설명**: `규칙/제약 → 플레이어 행동 → 경험(감정)`이 어떻게 이어지는지 설명. (오늘 렌즈가 밸런스·문맥 등이라면 그 관점에 맞게 연결)
- [ ] **반례·대안 1개 (시작값)**: 같은 규칙인데 예상과 다르게 돌아간 장면, 또는 내 가설 말고 다른 이유로도 설명할 수 있는 가능성 1개.
- [ ] **외부 검증 필요 1개 (선택, 시작값)**: `"기획 단계부터 2차 창작·스피드런을 노렸다"`나 `"시장에서 유행해 성공했다"`처럼 20분 플레이만으로는 알 수 없는 내용은 **`[미확인]`**으로 분리.
- [ ] **전이 실험 1개 (시작값)**: `"우리 게임의 ___을 ___으로 바꾼 뒤, [누구에게 / 어떻게] 플레이시켜 비교한다."`

---

## 3. FigJam 보드 5칸 안내 (선택 틀)
기존 FigJam 보드의 **5칸(루프 / 스토리 / 메커니즘 / 맵설계 / 메타)**은 생각을 정리하기 좋을 때 쓰는 **선택 틀**입니다.
- 다섯 칸을 매번 전부 채울 필요가 없습니다.
- **오늘의 렌즈와 상관없는 칸은 과감히 비워 두세요.** 억지로 다섯 칸을 다 채우는 것보다 오늘 렌즈에 맞는 장면 3개를 깊게 파는 것이 낫습니다.

---

## 4. 근거 등급 ①~④와 표시법
내 문장이 어디에 기댄 말인지 아래 등급으로 구분합니다. ①번(직접 경험)도 "모든 유저가 똑같이 느낀다"는 증거는 아니므로 주의합니다.

| 등급 | 근거 종류 | 설명 및 예시 | 함께 쓸 표시 |
|---|---|---|---|
| **①** | **직접 플레이·캡처** | 내가 플레이하며 찍은 화면, 소리 조건, 막힌 시간, 내 체감 | `[봤음]`, `[느꼈음]` |
| **②** | **제작자 공식 자료** | 스토어 설명, 패치 노트(예: 출시 후 스피드런 옵션 추가 로그), 개발자 인터뷰 | `[외부 근거]` |
| **③** | **외부 리뷰·반응** | 다른 유저 리뷰, 커뮤니티 반응, 플레이 영상 | `[외부 근거]` |
| **④** | **분석자 추정** | 관찰한 장면을 바탕으로 내가 세운 가설이나 제작 의도 추측 | `[추측]`, `[미확인]` |

## 5. 60분 분석 진행표 (아안·파이 공통, 시간은 시작값)
> 평일 기본 60분(시작값) 기준입니다. 잼 기간이나 학교 마감으로 바쁜 날에는 **최소판 30분(시작값: 플레이 10분 → 초안 10분 → 교차 질문 5분 → 수정 5분)**으로 줄여서 진행합니다. 중반까지는 서로의 글을 보지 않고 먼저 씁니다.

| 시간 (시작값) | 아안 (백지형) | 파이 (학습지형) | 남는 산출물 |
|---|---|---|---|
| **0~3분** | 지난 개념 2분 인출 + 오늘 렌즈와 내 예상 1개 선언 | 지난 개념 2분 인출 + 오늘 특화 질문 2개 선택 | 관점 헤더 |
| **3~23분** | 독립 플레이, 스크린샷·시간·장면 수집 | 독립 플레이, 입력·소리·UI 반응·장면 수집 | 각자 근거 장면 원자료 |
| **23~38분** | 서로 안 보고 **백지**로 주장·근거·인과 작성 | 서로 안 보고 **학습지** 공통 3개 + 특화 2개 작성 | 독립 개인 초안 |
| **38~48분** | 내 가설의 반례가 되는 장면 다시 해 보기 | 막혔거나 특이했던 장면 다시 해 보기 | `[봤음]`과 `[추측]` 분리 |
| **48~58분** | 파이 관찰 1개에 `"왜?"` 질문 + 대안 1개 제시 | 아안 주장에 내 직접 경험 1개로 질문·보완 | 합의점·차이점 기록 |
| **58~60분** | 질문 반영해 내 글 1곳 수정 + 우리 게임 전이 실험 1개 | 질문 반영해 내 글 1곳 수정 + 적용/확인법 1개 | 수정 표시 + 한 줄 결론 |
