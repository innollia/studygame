# innollia 백지 분석 가이드 (20~30분 분량)

이 문서는 빈칸을 채우는 학습지가 아니다. 게임을 20분 플레이한 뒤 **빈 문서(백지)를 열고 아래 1~6번 순서대로 자기 말로 빠르게 써 내려가는 훈련 가이드**다. 전체 작성 시간은 20~30분을 넘기지 않는다.

---

## 작성 전 헤더 (1분)
백지 맨 위에 아래 한 줄만 적고 바로 본문으로 들어간다.
- `[회차 / 날짜] 게임 제목 (플레이 시간: 00분 / 오늘 집중 관점: ...)`

---

## 백지에 이 순서로 써라

### 1. 핵심 루프 (Core Loop) — 3~4분
플레이어가 게임 안에서 30초~3분 단위로 끊임없이 반복하는 행동을 화살표(`→`) 하나로 묶어 적는다.
- **작성 방식**: `[행동(Action)] → [결과/보상(Reward)] → [성장/확장(Upgrade)] → [더 큰 도전(Challenge)]` 흐름을 한 줄로 먼저 쓰고, 그 루프가 왜 지루하지 않고 다음 턴/다음 스테이지를 누르게 만드는지 2~3문장으로 적는다.

### 2. 선택과 결과 (Meaningful Choices) — 4~5분
단순 반사신경이나 정답 맞히기가 아니라, 플레이어가 실제로 **트레이드오프(기회비용)**를 고민하게 되는 순간을 적는다.
- **작성 방식**: 플레이어에게 주어지는 선택지 A와 B가 각각 무엇을 얻고 무엇을 포기하게 하는지 적는다. 선택의 결과가 즉시 눈에 보이는지(단기 피드백), 몇 분 뒤에 스노우볼로 돌아오는지(장기 피드백) 구분해 적는다.

### 3. 메커니즘 - 역학 - 감정 (MDA) — 5분
규칙(Mechanics)이 실제 플레이 상황(Dynamics)을 만들고, 그것이 최종적으로 어떤 감정(Aesthetics)을 일으키는지 인과관계로 연결한다.
- **작성 방식**:
  - **M (메커니즘/규칙)**: 코드와 수치로 정해진 규칙 1~2개 (예: 재장전 중 이동속도 50% 감소)
  - **D (역학/창발적 상황)**: 그 규칙 때문에 플레이 중에 벌어지는 실제 행동 패턴 (예: 적이 몰려올 때 기둥 뒤로 숨어 타이밍을 재며 긴박하게 거리 조절)
  - **A (감정/경험)**: 그때 플레이어가 느끼는 감정 (예: 아슬아슬한 압박감과 위기 탈출의 쾌감)
  - 만약 규칙 하나를 제거하거나 수치를 2배로 바꾸면 D와 A가 어떻게 무너지는지 한 줄 덧붙인다.

### 4. 시스템 / 레벨 / UI / 밸런스 메모 — 5~7분
그날 주차의 주제에 맞춰 아래 네 가지 중 1~2개를 골라 깊게 적는다.
- **시스템**: 자원(체력, 돈, 시간, 스태미나 등)의 생성(Source)과 소모(Sink) 구조.
- **레벨**: 튜토리얼 없이 규칙을 어떻게 가르치는지(기믹 소개 → 응용 → 결합 → 시험).
- **UI/UX**: 플레이어가 순간적인 판단을 내릴 때 꼭 필요한 정보를 화면 어디에 어떻게 보여주는지, 조작 피드백(타격감, 사운드, 이펙트)이 명확한지.
- **밸런스**: 지나치게 강력한 지배적 전략(사기 빌드)이 있는지, 위험 부담(Risk)과 보상(Reward)의 크기가 비례하는지.

### 5. 플레이어 경험 곡선 (Interest Curve) — 3~4분
플레이 시작부터 20분이 지날 때까지 긴장감·흥미도가 어떻게 오르내렸는지 흐름을 그린다.
- **작성 방식**: `도입(호기심) → 첫 학습 → 첫 위기/막힘 → 돌파 → 피로 구간 → 클라이맥스` 중 어디에서 몰입이 깨졌고 어디에서 도파민이 터졌는지 짚는다. (플레이테스트 회차라면 관찰 대상자가 헤맨 지점을 여기에 기록한다.)

### 6. 내 게임에 가져올 것 1개 (Actionable Takeaway) — 2~3분
분석으로 끝내지 않고, 핸섬가이즈 팀에서 만들거나 다듬을 게임에 **이번 주 안에 바로 적용할 수 있는 구체적 규칙·연출·구조 1개**로 결론을 맺는다.
- **작성 방식**: "이 게임의 [어떤 장치]를 가져와서, 우리 게임의 [어떤 문제/상황]에 [이렇게 변형해] 적용한다" 형태로 딱 한 문단으로 끝낸다.
