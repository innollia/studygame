## 2. 실제 작성 예시 — D3 (A1: We Become What We Behold)
> `docs/plan-outline-v2.md`의 11/5(목) D3 회차에 바로 쓸 수 있도록 작성한 카드입니다.

```markdown
# [숙제 카드] 회차 ID: D3 (A1) | 대상: 아안·파이 | 날짜: 2026-11-05 (목)
- **오늘의 렌즈(집중 관점 1개, 시작값)**: MDA(규칙 Mechanics → 행동 Dynamics → 감정 Aesthetics)와 감정 변화
- **사전 읽기 자료 (10분, 시작값)**: MDA 논문 핵심 https://www.cs.northwestern.edu/~hunicke/MDA.pdf
- **분석할 게임**: We Become What We Behold https://ncase.itch.io/wbwwb (한국어 팬번역: https://game.hyeon.me/wbwwb/ )

## 1. 목표 (1개, 시작값)
- 이 게임의 **실제 규칙(M) 하나**가 플레이어의 **반복 행동(D)**을 어떻게 유도하고, 그 결과 내 **감정(A)이 언제 어떻게 바뀌었는지** 장면 근거를 들어 설명할 수 있다.

## 2. 분량 (정상 60분 · 최소판 30분, 시작값)
- **시작 전 필수 (2분, 시작값)**: D2에서 배운 '메커니즘과 의미 있는 선택' 개념 중 하나를 자료 없이 말하고 게임 예시 1개 대기 → 원문과 맞춰 보기.
- **정상판 (60분, 시작값 — 사전 읽기 10분 포함 시 총 70분)**:
  - 사전 10분: MDA 논문 핵심 개념(M·D·A의 차이) 확인 및 오늘의 질문 확인
  - 3~23분(20분): 각자 독립적으로 게임 플레이(처음부터 끝까지 1~2회 플레이하며 화면 캡처·감정 변화 시점 메모)
  - 23~38분(15분): 서로의 글을 보지 않고 각자 초안 작성
    - **아안**: `templates/analysis-guide.md` 기준으로 백지에 핵심 주장 1개 + 장면 근거 3개 + M→D→A 인과 설명 + 반례/대안 1개 + 전이 실험 1개 작성
    - **파이**: `templates/pai-worksheet.md` 기준으로 공통 질문 3개 + 오늘의 특화 질문 2개 + 끝맺기 2개 작성
  - 38~48분(10분): 다른 선택(예: 평화로운 장면만 찍기 등)을 해 보며 내 가설의 반례 장면 확인
  - 48~60분(12분): 서로 근거 질문 1개씩 주고받은 뒤, 내 글 1곳을 수정하고 우리 게임에 가져갈 점 1개 정리
- **최소판 (30분, 시작값 — 바쁜 날 선택)**:
  - 지난 개념 인출 2분 → 게임 플레이 및 캡처 10분 → 각자 독립 초안(M→D→A 연결 1개 중심) 10분 → 서로 질문 4분 → 내 글 1곳 수정 4분.

## 3. 마감
- **날짜·시각**: 2026-11-05 (목) 분석 세션 종료 시점 (구체 시각 미정)

## 4. 완료 기준 3개 (시작값: 3개)
- [ ] **기준 1 (오늘의 질문 3가지 연결)**: ① 실제 규칙 하나(예: 카메라로 무엇을 찍어야 뉴스가 되는가) → ② 그 규칙 때문에 반복된 행동 → ③ 플레이 중 감정이 **언제** 어떻게 바뀌었는지가 글에 연결되어 있다.
- [ ] **기준 2 (장면 근거와 확실성 분리)**: 실제 플레이 화면 캡처(또는 구체적 장면 묘사)가 붙어 있고, 내가 직접 본 사실(`[봤음]`), 내가 느낀 감정(`[느꼈음]`), 제작 의도나 원인에 대한 내 가설(`[추측]`)이 구분되어 있다.
- [ ] **기준 3 (독립 작성 후 수정 1곳)**: 처음엔 서로의 글을 보지 않고 썼으며, 마지막에 상대방의 질문을 받고 내 글을 고친(또는 이유를 들어 유지한) 흔적 1곳이 남아 있다.

## 5. 제출 위치
- **FigJam**: `A1 - We Become What We Behold` 섹션 (왼쪽 아안 칸 / 오른쪽 파이 칸)
- **디스코드**: 핸섬가이즈 채널에 FigJam 해당 섹션 링크 + 각자 오늘의 한 줄 주장 남기기

## 6. 피드백 안내
- **누가·언제·어떤 기준으로 보는가**: 분석 직후(또는 다음 회차 전) 매니저가 루브릭 **② 장면 근거·확실성**과 **③ 규칙→행동→경험 추론**을 중심으로 확인하여, 각자에게 강점 1개·필수 수정 1개·다음 한 걸음 1개를 전달하고 다음 분석 시작 때 반영 여부를 확인한다.
```
