## 핵심 결론 (5줄)

1. **고정된 항목을 매번 전부 채우는 대신, 매 회차 분석 관점 하나를 깊게 바꾼다.** MDA·FADT·문맥/형식 분석·플레이테스트를 번갈아 적용한다.
2. **기록 단위는 「장면/행동 → 관찰 → 원인 가설 → 대안 해석 → 확인 방법」**이다. 제작 의도와 플레이어의 경험을 동일시하지 않는다.
3. **파이=공통 질문 3개+회차 특화 질문 2개**, **아안=백지 주장 1개+관찰 증거 3개+반례 1개**로 서로 다른 도움 수준을 유지한다.
4. **게임 20개 모두 2026-10-22 기준 무료로 시작 가능**한 제작자 페이지·Steam 기본 무료판·무료 브라우저 데모를 골랐다. 30분은 *핵심을 관찰하는 창*이지 반드시 완주할 수 있는 길이가 아니다.
5. **FigJam의 기존 5칸(루프·스토리·메커니즘·맵설계·메타)은 유지**하되, 장면 증거·감정/효과·우리 게임 전이를 구분한다. 잼 중에는 회차를 억지로 넣지 않는다.

### 다른 게임에 적용 가능한 사고 단위

- **관찰(사실)**: “검이 바닥에 닿으면 진동·파티클이 나타났다.” *(시점 또는 캡처 첨부)*
- **가설(해석)**: “접지 상태를 알려 조작 오류를 줄이려는 피드백일 수 있다.”
- **대안 가설**: “직관성보다 코믹한 손맛을 늘리려는 연출일 수도 있다.”
- **검증**: “효과를 끄는 설정이 있는지, 처음 접하는 플레이어가 접지 상태를 더 잘 구별하는지 관찰한다.”
- **전이**: “우리 게임에서도 위험한 벽의 접촉 순간을 다른 표식으로 보여 준 뒤 플레이테스트한다.”

**근거의 급**: ① 직접 플레이·캡처·시각/음향 기록 ② 제작자 공식 문서/변경 내역 ③ 외부 리뷰·사용자 반응 ④ 분석자 추정. ①도 “다른 모든 플레이어가 똑같이 느낀다”는 증거는 아니다. FigJam 기존 첫 회차에서 “기획부터 팬아트·스피드런을 노렸다”는 말은 ④에 해당한다. 실제로 제작사 페이지에는 스피드런 설정 업데이트가 기록되어 있어 **출시 후 지원**은 확인되지만, **최초 기획 의도**까지 확정할 수는 없다. [공식 개발 로그](https://cosmicadventuresquad.itch.io/deepest-sword), [설정 업데이트](https://cosmicadventuresquad.itch.io/deepest-sword/devlog/252253/deepest-sword-new-pause-menu).

## 2. 분석 회차 14개 — 회차마다 중심 관점 하나

- **선행 A0**: 2026-10-22 Deepest Sword 분석은 이미 실시됨. 다시 새로운 A1로 세지 않고 **기준선 자료**로 보존한다.
- **순서**는 학습상의 제안 순서이며 고정 날짜가 아니다. 10/23~27 및 10/29~11/1의 잼 일정에는 일반 분석 회차를 강제하지 않는다. 잼 복기와 분석 회차는 구분한다.
- 각 회차 **권장 소요 60분**: 0~3분 관점 확인 → 3~23분 1차 플레이 → 23~38분 개인 기록 → 38~48분 장면 재현·증거 보강 → 48~58분 교차 질문 → 58~60분 결론. 설치 시간이 길면 미리 설치한다. *이 시간 분배 자체의 최적성은 미검증*.
- 아래 괄호는 **주 게임(대체·비교 게임)**. 선정 이유는 분석 과제를 잘 드러낼 만한 설계 특성에 따른 제안으로, 플레이 전 결론을 확정하지 않는다.

## 4. 기존 세 자료를 합친 분석 방식 — 60분짜리 FigJam 운영안

**기존 자료에서 그대로 가져올 것**
1. FigJam의 “루프 / 스토리 / 메커니즘 / 맵설계 / 메타” **5칸 분류**와 스크린샷 포스트잇. 첫 Deepest Sword에서는 아안이 복선·맵 재해석, 파이는 사운드 발생 조건·UI 반응을 찾은 것이 장점.
2. 기존 파이 학습지의 “무엇을 반복하나 / 중요한 선택 / 무엇을 바꾸면?”과 **플레이 우선, 리뷰 나중**.
3. 기존 아안 가이드의 작은 루프/큰 루프, MDA 인과 사슬, 관심 곡선, 내 게임에 가져갈 것. **다만 모든 회차에 같은 순서로 6개 영역을 모두 작성하게 하지 않음.** 중심 관점을 바꾸면 기록도 달라져야 한다.

**FigJam 배치**
- 상단 공통: 게임/링크/날짜/분석 관점 1개/플레이 조건(PC·버전·분수)/분석자/조작 경험.
- 중앙 **기존 5칸 그대로**: 루프 · 스토리 · 메커니즘 · 맵설계 · 메타. **오늘의 렌즈와 무관한 칸은 빈칸 허용**(억지 완성 금지).
- 옆 **장면 근거 보드**: [시점·스크린샷]→[관찰]→[가설]→[대안/검증]. 각자 **3개 이하의 결정적 장면**을 우선.
- 아래 **체감/반응**: 내가 느낀 것(직접 경험) / 상대가 말하거나 실제 보인 것(관찰) / 추정한 설계 목적(가설) **3개 표시 분리**.
- 하단 결론: [오늘의 한 문장 주장] + [반례 1개/미확인 1개] + [우리 게임에 적용할 점 1개와 확인법].
- 같은 보드 안의 **파이(오른쪽)**과 **아안(왼쪽)**은 중간까지 서로 글을 안 본다. 마지막 10분 서로 1개 장면을 질문한다. 두 사람이 각자 관찰한 차이는 없애야 할 오류가 아니라 비교 자료다.

### (c-1) 파이 — “학습지형” 템플릿 초안

> 아래 양식은 기존 templates/pai-worksheet.md를 대체하기 **전** 검토용 초안. 8개 질문 전부를 매회 강요하지 않는다.

**기본**: 회차 ___ / 게임 ___ / 날짜 ___ / 오늘 관점 ___ / 플레이 00분 / 처음 하는 게임? 예·아니오

**공통 질문 3개 (필수)**
1. “이 게임에서 **내가 실제로** 반복한 행동 1개는?” → 답 ___ / 시간·장면 ___
2. “**오늘 관점에서** 가장 확실히 본 장면 1개는?” → 게임이 한 일 ___ / 나는 어떻게 반응했나 ___ / 증거 캡처·시각 ___
3. “이 장면이 없거나 규칙이 달랐다면?” → 달라질 것 ___ / **내 추측**인 부분 ___

**회차 특화 질문 (위 A1~A14의 질문 3개 중 2개 선택)**
- 선택한 질문 ① ___ / 답 ___ / 장면 근거 ___
- 선택한 질문 ② ___ / 답 ___ / 장면 근거 ___

**끝맺기 2개**
- “오늘은 ___ 때문에 ___ 경험이 생겼다”라는 **주장 한 줄** ___
- “우리 게임에 가져갈 것 하나 / 실제 시험 방법” ___ / ___

**표시**: **[봤음]** 직접 확인 / **[느꼈음]** 본인 체감 / **[추측]** 목적·인과 / **[외부 근거]** 제작자·통계 URL / **[미확인]**.
**제출**: FigJam 오른쪽 칸 + 캡처/시각 링크 + 디스코드 한 문장 요약. **적은 양이어도 다섯 종류의 표시가 필요한 것은 아님**.

**파이 작성 예시 (Deepest Sword 재료를 이용한 형식 시연)**
- [봤음] 긴 칼을 바닥에 끌었을 때 진동/파티클이 나타남(정확한 초는 다시 확인).
- [추측] 조작 입력과 접촉 상태를 알려 주기 위한 즉시 피드백일 수 있음.
- [대안] 정보 전달보다 우스꽝스러운 표현을 강화하려는 연출일 수 있음.
- [검증] 해당 피드백을 화면 가림/소리 끔 등의 조건에서 비교해 초보가 접촉 여부를 인지하는지 본다.
- [적용] 우리 게임에서 조작 중요한 접촉 순간에 다른 신호를 붙여 테스트한다.

- [회차 / 날짜 / 게임 / 플레이 분 / 렌즈: ___]

**제출 기준만 고정 (작성 순서, 분량·칸 수는 자율)**
- **핵심 주장 1개**: “이 게임은 ___라는 장치로 ___라는 플레이 변화를 만든다.” (설계 의도라고 단정하지 않음).
- **근거 최소 3개**: 플레이 중 캡처/시각/상태 변화/소리 조건 등. 독립 근거가 부족하면 **동일 장면 변형 2회와 다른 장면 1회**로 명시.
- **인과 설명**: “규칙/제약 → 플레이 행동 → 경험” 연결. 오늘 렌즈가 문맥/경제 등이라면 그 관점에 맞게 치환.
- **반례·대안 1개**: 같은 규칙에서 예상과 달랐거나, 다른 설명도 가능한 장면.
- **외부 검증 필요 1개(선택)**: “개발자 의도/유행 원인/시장성” 등 20분 플레이만으로 확인 불가한 것을 미확인 표시.
- **전이 실험 1개**: “우리 게임의 ___을 ___으로 바꾼 뒤 [누구에게/어떻게] 비교한다.”

**작성 흐름 예시 (형식만)**:
자기 주장 자유 작성 → 그 아래 세 장면을 배치 → 서로 충돌하는 증거가 있으면 지우지 않고 표시 → 적용 실험 한 줄. *‘루프·MDA·UI·밸런스·흥미 곡선’ 5개를 매회 강제로 작성하지 않는다*. 아안이 이미 잘하는 레벨·메타 관찰을 살리되, 다음 회차에는 일부러 **감정/기능 피드백**으로 초점을 옮긴다.

### 60분 종료 절차 — 인풋/아웃풋

| 시간 | 아안 | 파이 | 산출물 |
|---|---|---|---|
| 0~3분 | 오늘 렌즈와 자신의 예상 1개 선언 | 오늘 두 특화 질문 선택 | 관점 헤더 |
| 3~23분 | 독립 플레이, 스크린샷·시간 기록 | 독립 플레이, 입력·소리·UI 반응 기록 | 각자 근거 장면 원자료 |
| 23~38분 | 백지로 논증/도식 작성 | 학습지 공통 3개 + 특화 2개 | 미완성 개인 초안 |
| 38~48분 | 가설에 반례가 되는 장면 재현 | 막혔던/특이했던 장면 재현 | [봤음]/[추측] 분리 |
| 48~58분 | 상대의 관찰 1개에 “왜?”와 대안 1개 | 상대의 주장에 직접 경험 1개로 반박/보완 | 합의점·차이점 |
| 58~60분 | 자기 게임의 적용 실험 1개 | 적용/확인법 1개 | 두 사람 한 줄 결론 |

**플레이테스트 회차 A12 예외**: 한 사람은 관찰자, 다른 사람은 초보 플레이어가 되는 순간부터 “완전한 외부 초보”가 아니다. 가능하면 게임 모르는 3자를 테스트 참여자로 구하고, 없으면 **친구 간 예비 테스트**라고만 표기. 초반에는 해설하지 않고 시간이 찍힌 행동을 남긴다. 녹화 시 동의를 먼저 받는다. [NN/g 진행 체크리스트](https://www.nngroup.com/articles/usability-checklist/).

### 완료 기준·사후 비교 (평가이지 정답 맞히기 아님)

- **관찰**: 장면이 어디서 나왔는지 재확인 가능한가?
- **추론**: “봤음/느꼈음/추측”을 분리했는가?
- **주제 집중**: 오늘 렌즈에 해당하는 관찰이 최소 1개 있는가?
- **이견 기록**: 둘이 다르게 느낀 부분을 삭제하지 않았는가?
- **전이**: 자기 게임에서 확인할 수 있는 작은 가설을 하나 만들었는가?

이 다섯 항목은 **운영 제안**이며 논문에 근거한 표준 루브릭 점수로 주장하지 않는다. 특정 회차에 적합하지 않은 항목은 평가에서 제외한다.

## 5. 첫 회차(Deepest Sword)에서 바로 바꿀 것

**아안에게**
- “복선1·2가 처음 보일 때와 검이 길어진 뒤” 장면을 이어 그린 것은 좋은 **레벨 분석**. 이를 주제 주장 하나로 앞에 올리고 시간순 캡처 세 장으로 증명한다.
- 이미 쓴 “루프=용에게 검 꽂기→칼 길이 증가”는 큰 루프이므로, “한 구간에서 지형을 넘어가는 조작→실수→복귀/재시도”라는 작은 반복을 나란히 놓는다. **모든 게임에 두 루프가 필수는 아니다.**
- “2차 창작/스피드런을 처음부터 노렸다”는 추측으로 남기고, 공식 변경 로그에서 **나중에 생긴 지원**과 **초기 기획 의도**를 구별한다. [공식 게임/개발 내역](https://cosmicadventuresquad.itch.io/deepest-sword).

**파이에게**
- 효과음이 **나는 조건뿐 아니라 나지 않는 조건**을 관찰한 것이 아주 좋은 입력/출력 증거. 1개만 골라 “어떤 조작 상태를 알리나/없는 경우 모호해지나?”로 발전시킨다.
- “클릭 시 색 변함” “창이 열림”을 **관찰**로, “오입력 방지/확실한 반응 전달”을 **가설**로 분리한다.
- 화면 접근성(장애·사용 환경 지원)과 진입 온보딩(처음 무엇을 할지 알기)은 다른 분석 항목. 리바인딩·카메라 흔들림 비활성화 같은 실제 설정을 근거로 접근성을 논할 수 있다. [개발사 설정 업데이트](https://cosmicadventuresquad.itch.io/deepest-sword/devlog/252253/deepest-sword-new-pause-menu).

**둘이 함께**: 보드의 다섯 칸 중 빈칸이 생겨도 괜찮다. 기존 피드백의 “본문에 관찰을 종합하라”는 조언을 유지하되, **본문을 과장으로 채우지 말고** 마지막 10분에 가장 중요한 3장면을 하나의 설명으로 연결한다.

## 6. 실제 적용 우선순위

1. **지금**: 이 문서를 분석 회차와 게임 풀의 정본 **후보**로 두고, A0 원문은 손대지 않는다. 기존 템플릿 두 파일도 오케스트레이터가 승인할 때까지 변경하지 않는다.
2. **다음 분석 가능한 날**: A1 — MDA/감정, *We Become What We Behold* (한국어 팬 번역 선택 가능). 첫 3분 관점 확인, 20분 게임, 15분 개별 기록, 10분 증거 재확인, 10분 토론, 2분 다음 실험.
3. **회차 직후**: 디스코드에 각자 “오늘 렌즈 / 주장 / 근거 장면 / 미확인 / 다음에 검증할 1개” 다섯 구절만 공유한다.
4. **3회차 뒤**: 아안이 자유롭게 쓴 기록에서 **근거→추론→반례**가 실제로 증가했는지, 파이가 5개 공통/특화 질문을 과부하 없이 수행했는지를 비교해서 템플릿을 수정한다.
