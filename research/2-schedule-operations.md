# 리서치 2 — 일정 짜기와 계획 운영 (2026-10-22 조사)

> 적용 기간: 2026-10-23 ~ 2026-11-30 / 대상: 아안·파이 / 상태: 조사 권고안(원래 plan.json은 수정하지 않음)

## 핵심 결론 5줄

1. **게임잼 2개가 있는 10/23~11/1을 정상 수업 주간으로 세지 않는다.** 이 기간은 잼 제작·복기를 우선하고 강의는 0~10분 최소판만 허용한다.
2. **21일짜리 1회독을 11/2~11/23의 21회 학습으로 이동**한다. 11/6은 온전한 쉬는 날이다. 주차 수는 실제 경과일이 아닌 수업 회차로 센다.
3. 학교 날의 **6시간 30분(390분)은 순수 공부 시간이 아닌 가용 창**이다. 우선 120분 개별 창 + 270분 공동 창으로 가정하고, 그 안에 학교 과제·게임 제작·휴식·버퍼를 함께 넣는다.
4. **25분/50분 자체가 정답은 아니다.** 집중·휴식 단위는 작업 종류와 실제 피로·완료 기록에 따라 바꾼다.
5. **밀린 할 일을 다음 날에 전부 얹지 않는다.** 주 10분 리뷰, 최소판, 보호된 버퍼, 중요도 기반 재배치로 커리큘럼의 완주보다 학습의 질과 지속성을 지킨다.

### 시간 단위에 대한 판정

- **25+5**: 집중을 시작하기 어려운 과제, 영상을 능동적으로 끊어 기록할 때 *실험 가능한 형식*.
- **50+10**: 분석, GDD 작성, 프로토타입 설계처럼 한 덩어리 작업을 이어 갈 때 *실험 가능한 형식*.
- **자율 종료**: 작업 흐름이 뚜렷하게 이어질 때 선택하되 50~60분 정도 지났으면 피로 확인.
- 2023 연구는 계획된 휴식에 비교적 호의적이지만 2025 연구는 성과 차이를 확인하지 못했다. 따라서 “포모도로가 과학적으로 가장 좋다”는 주장 **불가**. 시작 후 1주일은 각자 집중·피로·완료 여부로 맞춘다.

## 3. 날짜 유형별 하루 템플릿 (b)

**시간의 계산 경계**: “학교 날 둘이 함께 작업 가능한 6시간 30분, 그중 아안의 교내 여유 2시간”은 390분과 별개로 120분을 더하지 않는 것으로 해석한다. **임시 운영 가정**은 각자 독립 시간 120분 + 공동으로 시간을 맞출 수 있는 나머지 270분이다. 실제 디스코드 동시 접속 시간이 다르면 270분을 먼저 수정한다. 전부 게임기획 공부로 채우지 않는다. 각 표의 분은 연구 결과가 아니라 사용자 제약을 만족시키도록 만든 **초기 배치안**이다.

### 유형 1 — 일반 학교 날 (하루 가용 창 390분)

| 구간 | 아안 | 파이 | 분 |
|---|---|---|---:|
| 교내 독립 A | 학교 수행·마감 과제 우선 | 관련 게임개발·UI/UX·기초 지식 영상 선택 시청 | 50 / 45 |
| 교내 독립 B | 오늘 강의의 사전 개념 읽기·전 회차 회상 | 영상 3줄 요약 + 게임에 쓸 점 1개 | 20 / 20 |

- 아안의 게임기획 학습은 사전 20 + 공동 55 = **75분**. 파이는 학교 영상 45분에 20분 능동 기록이 따르고, 공동 기초 학습 55분에도 참여한다.
- 파이의 “최대한 많이 영상 보기”는 초기에 45분의 **시험 배치**로 시작한다. 학교·과제 부담이 적은 날 추가 시청은 가능하지만, 학습 기록 없이 조회수만 늘리지는 않는다.
- 학교 관련 고정 의무가 큰 날에는 아안/파이 모두 **버퍼→제작 시간→강의 최소판** 순서로 줄인다. 학교 마감을 희생해 390분표를 맞추지 않는다.

### 유형 3 — 게임잼 날

**평일 잼 날, 390분 가용 창 가정**

- **아안 교내 120분**: 학교 과제 70 + 게임기획 회상 10 + 잼 자기 담당 준비 20 + 버퍼 20.
- **파이 교내 120분**: 학교 과제 35 + 잼과 연관된 개발 영상 35 + 영상의 적용점 10 + 에셋/기능 조사 20 + 버퍼 20.
- **공동 270분**: 시작 회의 15 + 핵심 제작 180 + 휴식 10 + 다른 플레이어 시점 테스트 30 + 문제 우선순위 결정 15 + 버퍼 20.
- **강의 새 진도는 0분**, 그날 개발 중 실제로 부딪힌 기획 원리를 1줄 적는 것은 허용. 아안 회상 10분은 이 최소판에 해당한다.

**주말 잼 날(동시 작업 270분 예시)**

- 아안·파이 각각: 우선순위 정리 15 + 제작 180 + 휴식 10 + 테스트 30 + 결과 기록/수정 분류 15 + 버퍼 20 = **270분**.
- 다른 마감이 있거나 참여 시간이 부족하면 제작 180분을 먼저 축소. 잼 운영시간과 마감시각은 각각 확인 전까지 미확인.

### 유형 4 — 복기 날 (10/28·11/1, 공동 90분을 목표)

| 시간 | 아안 | 파이 |
|---|---|---|
| 10분 | 스크린샷·버전·피드백·계획 기록 모음 | 플레이 장면·버그·유저 반응 모음 |
| 20분 | 예상한 핵심 경험과 실제를 비교 | 가장 이해하기 어려웠던 규칙·UI를 기록 |
| 20분 | 가장 큰 설계 판단 2개와 결과 해석 | 실제 플레이 증거로 동의/반례 제시 |
| 20분 | 개선할 점의 우선순위 합의 | 같이 결정 |
| 10분 | 다음 잼에도 재사용할 원리 1개 | 자기 게임에 옮길 원리 1개 |
| 10분 | 다음 행동 1개씩 지정하고 종료 | 함께 |

- **11/1 일정 충돌**: 11/1이 slap jam 최종 제출일이면서 복기 예정일이다. 최종 제출이 끝나지 않았다면 그날 90분 복기는 강제하지 않고 **10분 사건 메모만** 남긴다. 나머지 80분은 11/2 또는 가장 가까운 잼 외 시간으로 이동하되 D1과 병행이 벅차면 D1 이동을 우선 검토한다.
- 게임잼에서 학습한 것과 강의의 정상 학습 회차를 **중복 인정하지 않는다**.

### 유형 5 — 쉬는 날 (11/6)

- **아안 0분, 파이 0분: 의무 작업 없음.** 잼 미완료/밀린 강의 보충도 요구하지 않는다.
- 본인이 원할 때만 5분 기록 가능하지만 이를 ‘필수 최소판’이라 하지 않는다.
- 다음 날 D5로 복귀하며 연속 기록이나 보상 체계를 초기화하지 않는다.

### 최소판 / 낮은 가용성일 때

- **평소 학교 날 정상 75분 → 최소판 30분**: 5분 전 개념 회상 + 15분 해당 공식 자료의 한 소단위 + 10분 서로 핵심·질문 기록.
- **주말 정상 90분 → 최소판 30분**: 전 회차 과제의 핵심 요구 1개 읽기(10) + 짧은 적용(15) + 기록(5).
- **잼 날 최소판 0~10분**: 지난 개념 하나만 게임 작업에 연결하고 끝낸다.
- **쉬는 날 최소판 0분**: 필수 작업 없음.
- 최소판은 학습 완료로 무조건 자동 표시하지 않고 ‘최소판 수행’으로 기록한다. 2회독 공식 과제의 통과 기준을 대체하지 않는다.

## 4. 3주 1회독과 게임잼 충돌 처리 (c)

### 선택지 비교

| 안 | 결과 | 판단 |
|---|---|---|
| 원래 달력 10/23~11/12 고수 | 잼 2개와 새 강의가 중첩, 짧은 시간에 공식 과제·분석 압박 증가 | **비추천** |
| 21일 안에 강의 영역 축소 | 날짜는 지키지만 게임기획 커리큘럼의 전체 지도를 잃을 수 있음 | 공식 자료를 전혀 못 보는 비상시에만 |
| 10/23~11/1 잼 중심, 11/2~11/23 D1~D21 | 21회라는 학습 범위를 보존, 잼에 제대로 참가하고 별도 회고 가능 | **권고** |

**무엇을 줄일지 우선순위**
1. **줄이지 않음**: 각 영역이 대학에서 무엇을 다루는지 파악, 공식 과제의 요구 사항 한 개 읽기, 게임 분석 6회, 1회독 종료의 전체 지도.
2. **먼저 줄임**: 동일 주제 동영상 2~3개 연속 시청, 같은 내용을 반복 설명하는 보충 자료, 과제를 요구 이상으로 꾸미는 작업.
3. **부담이 과하면 최소판**: 강의 하나를 온전히 보기보다 syllabus/calendar/assignments에서 정확한 항목을 찾고 이유를 적는 것. 단순히 링크 클릭한 것을 학습 완료로 셈하지 않음.
4. **학습과 잼의 연결**: 플레이테스트와 복기에서 나온 문제를 D15~D20 학습 재료로 재활용. 잼 활동 자체를 강의 시청이나 공식 과제 완료로 허위 처리하지 않는다.

## 5. 밀렸을 때 재조정 규칙 5개 (d)

1. **일일 상한 유지**: 교내 120 + 공동 270의 가용 창을 넘기지 않는다. 계획대로 되지 않았다고 수면·학교 과제 시간에 강의를 덧씌우지 않는다. **버퍼는 ‘기본으로 비워 두는 칸’**이다.
2. **기록된 실제 시간으로 다시 추정**: 과제 시작 전 예상 30분, 종료 후 실제 48분이었다면 다음 유사 활동은 30분 대신 최근 유사 작업의 실제 시간을 참조한다. 유사 표본이 3개 미만이면 정확한 예측인 양 숫자 하나를 고정하지 않는다.
3. **밀린 날 전부 이월 금지**: 한 회차가 빠지면 가장 가까운 빈 날이나 11/24~29의 보강 칸으로 옮기고 이후 날짜에 강의를 한 회차 더 얹지 않는다. **2회차 이상 밀리면** D21 종료일을 늦추거나 선택 영상 수를 줄인다.
4. **동시에 붙잡는 일 제한**: 같은 공동 시간에 ‘공식 학습 1개 + 실제 제작 핵심 1개’만 진행 중으로 둔다. 새로운 생각은 백로그에 두고 마감·학습 목표와 연결되는지 먼저 판정한다.
5. **미이행 이유를 사람 평가로 바꾸지 않기**: 원인을 (a) 마감 충돌 (b) 예상시간 오류 (c) 자료 접근 문제 (d) 과제 크기 (e) 피로·휴식 부족 (f) 우선순위 변경 중 하나로 기록. 다음 주엔 **시간·범위·도구 중 한 가지를 수정**한다.

### 매니저가 쓰는 의사결정 절차

- 오늘 학교 긴급 제출/시험과 잼 공식 마감이 있는가? → 그쪽을 먼저 확보.
- 남은 공동 시간과 컨디션은 어떤가? → 정상 75~90분 / 최소판 30분 / 잼 최소판 / 쉬는 날 0분 중 택1.
- 같은 유형의 실제 소요 기록이 있는가? → 있으면 실제 기록으로 예측, 없으면 추정임을 명시.
- 30분 버퍼를 넘겨 일이 밀렸는가? → **내일에 누적하지 말고** 다음 주 슬롯 또는 보강 주간으로 이동.
- 계획은 결과 달성을 위한 가설이다. ‘계획을 지켰느냐’뿐 아니라 ‘게임기획 판단·분석이 나아졌느냐’를 본다.

## 7. 기록 방법과 7일 보정 실험

기존 data/progress.json에는 done/date/note만 있다. **완료 상태를 임의 변경하지 않고** 매니저가 각자의 note 또는 별도 기록에 다음 수치를 남기면 된다.

| 필드 | 예 |
|---|---|
| 날짜·사람 | 2026-11-03 / 파이 |
| 회차·작업 | D2: 게임 메커니즘 자료와 적용 |
| 오늘 유형 | 학교 / 주말 / 잼 / 복기 / 휴식 |
| 사전 예상·실제 | 55분 / 72분 |
| 수행 수준 | 정상 / 최소판 / 미수행 / 휴식 |
| 남은 근거 | FigJam 링크 또는 게임 화면 메모 |
| 이탈 원인·수정 | 링크 오류로 +17분 → 다음엔 미리 링크 확인 |

- **11/2~11/8**은 최초 조정 실험: 25+5 / 50+10 / 자유 휴식 중 하루의 활동에 맞게 선택. 7일이 지나면 개인별 **종료한 과제 수, 예측 오차, 피로**를 대조. 우열을 미리 단정하지 않는다.
- **버퍼 30분/270분**은 현장에서 수정할 초기값. 버퍼가 실제로 3일 연속 모자라면 예상 소요 시간을 늘리거나 과제 수를 줄이고, 대부분 남으면 시간을 반환한다.
- **‘한 번도 안 빠진 연속 기록’ 대신 ‘복귀까지 걸린 시간’**도 보자. 쉬는 날을 0점으로 처리하지 않는다.
- 일정 운영의 평가 기준: 과제 증거가 남는가, 분석의 주장에 실제 플레이 근거가 붙는가, 예측 오차가 줄어드는가, 학교·잼 마감을 침범하지 않는가.

## 8. 적용 시 주의·미확인

- 일정은 저장소 research/prompts.md 공통 배경과 data/plan.json을 읽어 작성했다. 두 사람의 실제 등하교·취침시각, 개인별 주말 가용시간, 11/1 잼 종료/복기 시점, 향후 시험·수행평가의 정확한 충돌 여부는 **미확인**이다. 따라서 모든 표는 시계 시각이 아닌 **분량 배분**으로 기재했다.
- “6시간 30분 중 2시간이 교내 여유”를 보수적으로 읽어 120분 독립 + 270분 공동으로 운영했다. **390분이 실제 순수 공동 시간이라는 별도 합의가 있었다면 분배 재확인**이 필요하다. 학교 중 실제 수업 시간을 임의로 프로젝트에 할당하지 않는다.
- 연구는 대체로 성인·대학생 대상이므로 16~17세 고교생 두 명에게 효과크기를 그대로 보장하지 않는다.
- 쉬는 날 유지와 최소판은 **완벽한 출석**보다 회복·꾸준한 복귀를 우선하는 운영 제안이다. 연구에 이름 붙은 확립된 매뉴얼로 제시하지 않는다.
- 이는 **리서치 결과물**이며, 승인 없이 data/plan.json의 시작 날짜나 진도 완료 표시를 바꾸지 않았다. 오케스트레이터는 이 권고를 검토한 뒤 실제 일정과 일일 계획에 반영할 수 있다.
