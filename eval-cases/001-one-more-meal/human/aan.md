# 아안의 UI 평가 — 한 끼의 무게 v5 (피그잼 보드 옮겨 적기)

출처: human/aan-board-1.webp, human/aan-board-2.webp (포스트잇 + 빨간 펜 표시)
옮긴 사람: AI. 아안이 쓴 글은 따옴표 안에 그대로 옮겼다. [해석]은 AI가 표시 위치를 보고 덧붙인 뜻풀이다. 틀렸으면 아안이 고쳐 주면 된다.
참고: 아안은 문제가 너무 많아서 평가를 중간에 그만두었다. 그래서 소매치기 패널(s08·s09)과 플레이 안내(s12)에는 표시가 없다.

## 보드 1

### A1. 타이틀 화면 (s01·s02를 이어 붙인 캡처)
- 빨간 밑줄: 헤더 "살아내는 일에 관하여", 장소 줄 왼쪽·오른쪽 글, 제목 위 "내일도 함께 있기 위한 이야기", 시작 버튼 위 소개 문장, 버튼 아래 "아이를 위해, 또 한 번의 아침을", 그림 속 "한 접시 두 개의 숟가락", 아래 "✦ 한 접시 두 개의 숟가락 살아야 할 이유 하나", 푸터 "ONE MORE MEAL · ONE MORE MEAL", 푸터 오른쪽 글
- 빨간 물결선: 키 안내 줄 전체
- 화살표 + "??": "훔치는 손끝에, 지켜야 할 내일이 있다"
- 빨간 동그라미: "하루씩, 더 오래 살아남으세요. / 빛이 사라지기 전에 돌아가세요."
- 포스트잇: "게임만 있으면 되는데 게임 겉에 뭐 이상한게 막 붙어있어요 파이님"
- [해석] 게임 화면 바깥에 꾸밈 문구, 키 안내, 푸터가 너무 많이 붙어 있다. 같은 문구도 되풀이된다("한 접시 두 개의 숟가락" 두 번, "ONE MORE MEAL" 두 번).

### A2. 첫 대화 상자 (s03)
- 빨간 그림: 말풍선 꼬리 아래 빈자리에 사람(막대 인형)과 화살표를 그려 넣음
- 포스트잇: "대사 직접 안 썼음 / 아이는 아빠가 일하러... 이건 왜 있어 / 더 듣기는 뭐야 다음도 아니고 / 대사 박스 자체가 gpt slop이야"
- [해석] ① 말풍선이 가리키는 곳에 말하는 아이가 없다. ② 대사 아래 설명 문장 "아이는 아빠가 일하러 가는 걸 알고 있습니다."는 필요 없다. ③ 버튼 이름 "더 듣기"가 어색하다("다음"이면 된다). ④ 대사 상자의 글이 AI가 쓴 티가 난다(사람이 직접 쓰지 않았다).

### A3. 글꼴과 장르가 안 맞음 (다른 게임 아이템 카드 "흰색 마녀 분필"을 참고 이미지로 붙임)
- 포스트잇: "케주얼 게임이면 이렇게 귀여운 동글동글한 폰트 써야지 무슨 명조를 쓰고있어"

### A4. 일시정지 메뉴 (s10)
- 빨간 밑줄: "CHAPTER 01", "잠시, 숨을 고르며.", "거리는 여기서 기다립니다. 준비가 되면 이야기를 계속하세요."
- 포스트잇 1: "챕터 2는 어디야"
- 포스트잇 2: "키바인드를 한번 더 들어가야 나오게 하기"
- [해석] ① "CHAPTER 01"이라고 써 놓았는데 챕터 2가 없다(또는 어디서 가는지 모른다). 꾸밈 제목과 문장도 필요 없다. ② 조작키 표가 일시정지 첫 화면에 바로 펼쳐져 있다. 한 단계 더 들어가야 나오게 바꾸자.

## 보드 2 — 1일째 HUD (s05)

### A5. 하루 목표·실패 조건 문구
- 빨간 밑줄: "가게 문이 닫히기 전에 돌아가야 한다.", "연속 굶은 밤 · 0 / 2"
- 포스트잇: "배드엔딩 조건 스포"
- [해석] 몇 밤 굶으면 끝나는지를 처음부터 HUD에 보여 주는 것은 결말을 미리 알려 주는 셈이다.

### A6. 오른쪽 위 HUD
- 포스트잇: "오늘의 식사→밤 / 돈 0/5 → null"
- [해석] 오른쪽 위 "오늘의 식사" 자리는 "밤"(남은 시간)으로 바꾸고, "돈 0/5"는 지운다.

### A7. 같은 UI가 두 군데 있고, 들킨 횟수만 숫자다
- 포스트잇: "같은 ui가 두군데 있음 / 들킨 횟수는 지혼자 0/3으로만 되어있음 다른 숫자는 다 시각화 있는데"

### A8. 가게 간판
- 포스트잇(가게 문 앞, 간판 바로 옆): "간판 ㅇㄷ"
- [해석] 간판이 어디 있는지(무슨 가게인지) 안 보인다.

### A9. 비네팅
- 포스트잇: "비네팅 굳이 왜?"
- [해석] 화면 가장자리를 어둡게 하는 효과가 왜 필요한지 모르겠다.

### A10. 전체 톤
- 포스트잇: "UI가 전체적으로 게임의 플레이 방식이랑 괴리감이 있음. UI: 진지하고 명조체 / 플레이: 슬금슬금 으흐흐 얍 케케케 후다닥x100"
