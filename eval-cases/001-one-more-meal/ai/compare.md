# 평가 비교 — 한 끼의 무게 v5 (LEARN-COMPARE, 2026-10-24)

비교한 것: 아안 평가(human/aan.md, 피그잼 보드 2장을 옮겨 적음)와 AI 평가(ai/review.md, 아안 평가를 읽기 전에 써서 고정해 둔 것). 파이 평가는 없어서 파이 열은 모두 '-'다.
읽는 법: AI 평가는 정답이 아니라 "세 번째 평가자"의 의견이다. 파이가 없으므로 이 표의 `셋 다 찾음`은 **아안과 AI가 둘 다 찾았다**는 뜻이다.
범위 차이: 아안은 문제가 너무 많아 중간에 멈췄다. 아안의 표시는 s01~s05와 s10까지 있고, 소매치기 패널(s08·s09)과 플레이 안내(s12)에는 없다. 그래서 그 화면의 문제가 `AI만 찾음`으로 나온 것은 "아안이 놓쳤다"는 뜻이 아니라 **아직 거기까지 보지 않았다**는 뜻이다.

## 문제 단위 비교

| 문제 | 아안 | 파이 | AI | 판정 |
|---|---|---|---|---|
| 1. HUD 왼쪽 위 "연속 굶은 밤 0/2"·하루 목표 문구 (s05) | A5: 밑줄 + "배드엔딩 조건 스포". 보여 주지 말자는 쪽 | - | F1: 너무 흐리고 작아서 안 읽힌다. 더 크고 잘 보이게 하자는 쪽 | 서로 다름 → 직접 확인 필요. 같은 자리를 짚었는데 고치는 방향이 반대다 |
| 2. 돈·오늘의 식사가 HUD에 두 번 나옴 (s05 오른쪽 위 ↔ 아래) | A7 "같은 ui가 두군데 있음", A6 "오늘의 식사→밤 / 돈 0/5 → null" | - | F5 (심각도 2) | 셋 다 찾음. 아안은 "오른쪽 위를 밤(남은 시간)으로 바꾸고 돈은 지운다"는 구체적인 대안까지 냈다 |
| 3. "들킨 횟수"만 아이콘 없이 숫자 0/3 | A7 "지혼자 0/3으로만 되어있음 다른 숫자는 다 시각화 있는데" | - | F1 수정안 ②에서 아이콘으로 바꾸자고 함. 다만 문제를 "가독성"으로만 봤다 | 셋 다 찾음. 고치는 방법은 같다. 하지만 "다른 자원은 그림인데 이것만 숫자"라는 **일관성(C08)** 문제로 본 것은 아안이다. AI는 이 관점을 따로 적지 않았다 |
| 4. 게임 화면 바깥(헤더·장소 줄·키 안내·푸터)이 너무 많음 (s01·s02) | A1 "게임만 있으면 되는데 게임 겉에 뭐 이상한게 막 붙어있어요" | - | F6: 이 바깥 부분 때문에 720px 창에서 스크롤이 생긴다. 그 밖의 문제: 헤더 글자가 작고 흐리다 | 셋 다 찾음. 이유는 다르다(아안: 쓸데없음 / AI: 화면이 잘리고 스크롤됨). 고치는 방향(바깥을 숨기기)은 같다 |
| 5. 타이틀의 같은 문구 되풀이: "한 접시 두 개의 숟가락" 두 번, 푸터 "ONE MORE MEAL · ONE MORE MEAL" | A1 밑줄 | - | 언급 없음 | 학생만 찾음. s02에서 확인했고 맞다(AI가 놓친 것) |
| 6. 타이틀 아래 이야기 문구 "훔치는 손끝에…", "하루씩, 더 오래… 빛이 사라지기 전에 돌아가세요." | A1 화살표 "??"와 동그라미. 이유는 적지 않음 | - | "빛이 사라지기 전에"를 HUD의 "가게 문이 닫히기 전에"와 마감 표현이 다른 예로만 적음(심각도 1, 확신도 낮음) | 서로 다름 → 직접 확인 필요. 아안이 "??"를 붙인 이유를 알아야 같은 문제인지 판정할 수 있다 |
| 7. 타이틀 키 안내 줄 (s02) | A1 빨간 물결선. 이유는 적지 않음 | - | F3: Q·SPACE가 빠져 있고, 키 이름이 설정 화면과 다르다 | 서로 다름 → 직접 확인 필요. 물결선이 "지워라"인지 "틀렸다"인지 알 수 없다 |
| 8. 첫 대화에서 말하는 아이가 화면에 안 보임 (s03) | A2: 말풍선 꼬리 아래 빈자리에 사람을 그려 넣음 | - | 판단 못 함. "800px 캡처로는 판별 못 했다"며 플레이테스트 필요로 미룸 | 학생만 찾음. s03을 다시 보니 꼬리가 가리키는 왼쪽 아래에는 벽과 상자뿐이다. 보이는 사람은 어른 남자 둘이다. 아안이 맞다(AI가 놓친 것) |
| 9. 대화 버튼 이름 "더 듣기" (s03) | A2 "더 듣기는 뭐야 다음도 아니고" | - | 잘된 점으로 꼽음. "1/3 → 3/3"과 함께 버튼이 "거리로 나서기"로 바뀌는 흐름을 칭찬 | 서로 다름 → 직접 확인 필요. 둘 다 맞을 수 있다. AI가 칭찬한 것은 "몇 장 남았는지 보이는 것"이고, 아안이 지적한 것은 버튼 **낱말**이다. 진행 표시는 그대로 두고 낱말만 "다음"으로 바꾸는 방법이 있다 |
| 10. 대사 아래 설명 문장 "아이는 아빠가 일하러 가는 걸 알고 있습니다." (s03) | A2 "이건 왜 있어" | - | 언급 없음 | 학생만 찾음. 대사만으로 알 수 있는 내용을 한 번 더 설명하는 문장이라 화면 글만 늘린다. 타당한 지적이다 |
| 11. 대사 글 자체가 AI가 쓴 티가 남 | A2 "대사 직접 안 썼음", "gpt slop" | - | 언급 없음(글의 질은 UI 평가 범위 밖으로 봄) | 학생만 찾음. UI 문제라기보다 **글쓰기** 문제다. 파이와 따로 이야기할 거리다 |
| 12. 명조체·진지한 UI가 빠르고 가벼운 플레이와 안 맞음 | A3 "케주얼 게임이면… 동글동글한 폰트", A10 "UI: 진지하고 명조체 / 플레이: 슬금슬금 으흐흐 얍 케케케 후다닥x100" | - | 문제로 올리지 않음. 제작자(파이)의 의도를 unknown으로 두고 플레이테스트 필요(C12)로만 적음 | 학생만 찾음. 다만 맞는지는 **파이가 의도한 분위기**에 달려 있다. AI는 의도를 몰라서 판단하지 않았다 |
| 13. 일시정지 꾸밈 글 "CHAPTER 01 / 잠시, 숨을 고르며. / 거리는 여기서 기다립니다…" (s10) | A4 밑줄 + "챕터 2는 어디야" | - | 언급 없음 | 학생만 찾음. "CHAPTER 01"이라고 쓰면 다음 챕터가 있을 거라고 기대하게 된다. 맞는 지적이다 |
| 14. 조작키 표가 일시정지 첫 화면에 바로 펼쳐져 있음 (s10) | A4 "키바인드를 한번 더 들어가야 나오게 하기" | - | 키 변경 기능은 잘된 점으로 꼽음. "이야기로 돌아가기" 버튼이 스크롤 아래로 밀리는 것은 따로 적음(심각도 1) | 서로 다름 → 직접 확인 필요. AI는 **기능**을, 아안은 **배치**를 봤다. 아안의 방법대로 표를 한 단계 안으로 넣으면 AI가 적은 "돌아가기 버튼이 안 보임"도 같이 풀린다 |
| 15. 가게 간판이 잘 안 보임 (s05) | A8 "간판 ㅇㄷ" | - | s08에서 다른 글자와 겹치는 것만 적음. s05의 간판은 언급 없음 | 학생만 찾음. s03·s05에서 간판 글자는 가로등 옆의 작은 흰 글자뿐이다. 무슨 가게인지 찾기 어렵다는 지적은 타당하다 |
| 16. 화면 가장자리 비네팅(어둡게 하는 효과) | A9 "비네팅 굳이 왜?" | - | 언급 없음 | 학생만 찾음. 비네팅이 있는 것은 맞다. 하지만 왜 문제인지(분위기가 무거워진다? 어두운 모서리에 놓인 HUD가 더 안 보인다?)를 적지 않아서 아직 문제로 확정할 수는 없다 |
| 17. 튜토리얼 상자 아래 문장의 앞이 잘림 "하기 전까지 거리는 멈춰 있어요." (s05) | 표시 없음. 아안 보드 2의 캡처에는 보인다 | - | F4 (심각도 2, 확신도 높음) | AI만 찾음 |
| 18. 소매치기 패널: 안내가 늦게 나오며 패널을 밀어냄, "?→E" 규칙이 작은 글자에 묻힘 (s08·s09) | 그 화면까지 보지 않음 | - | F2 | AI만 찾음(아안 평가 범위 밖) |
| 19. 같은 키를 화면마다 다르게 부름, E·A/D·SPACE 설명 충돌 (s02·s08·s10·s12) | 7번 물결선 말고는 없음 | - | F3 | AI만 찾음 |
| 20. 1280x720 창에서 게임 화면이 잘리고 페이지가 스크롤됨 | 4번과 관련 있음 | - | F6 | AI만 찾음(스크롤·잘림이라는 관점). 고치는 방향은 4번과 같다 |
| 21. 플레이 안내가 1,528자 글 한 덩어리 (s12) | 그 화면까지 보지 않음 | - | F7 | AI만 찾음(아안 평가 범위 밖) |

정리: 둘 다 찾음 3건 / 학생만 찾음 8건 / AI만 찾음 5건 / 서로 다름 5건.
아안만 찾은 8건 가운데 5·8·10·13·15번은 화면에서 다시 확인했고, 타당한 지적이다. AI가 놓쳤다. 특히 8번은 AI가 "판별 못 함"으로 미뤄 둔 것을 아안이 직접 짚었다. 11·12번은 UI보다 글쓰기·분위기 문제이고, 16번은 이유가 더 필요하다.
보는 방향도 달랐다. 아안은 "이게 왜 있어 / 빼자" 쪽(군더더기·톤)을 많이 봤고, AI는 "읽히나 / 조작을 아나" 쪽(가독성·안내 일관성)을 많이 봤다. 어느 쪽이 맞다기보다 서로 못 본 곳을 채워 준다.

## 둘이 직접 확인해 볼 것

1. **"연속 굶은 밤 0/2"를 숨길까, 크게 보여 줄까(1번).** 아안은 "스포"라고 했고 AI는 "안 보여서 위험하다"고 했다. 먼저 파이에게 "굶어서 끝나는 걸 플레이어가 미리 알고 긴장하길 바라는지, 겪고 나서 놀라길 바라는지"를 묻는다. 그다음 처음 하는 친구에게 s05를 3초 보여 주고 "오늘 안 먹으면 어떻게 돼?"라고 물어본다.
2. **"더 듣기"를 "다음"으로 바꿀까(9번), 아이는 어디 있나(8번).** 친구에게 s03을 보여 주고 "누가 말하고 있어?", "저 버튼을 누르면 무슨 일이 일어날 것 같아?"를 묻는다. 대답이 "몰라" 또는 "대화를 더 듣는 선택지"면 아안의 지적이 맞다.
