# UI 수정 지시서 — 한 끼의 무게 (games/robberfather)

근거: gamedesign-study `eval-cases/001-one-more-meal/`(AI 평가 + 아안 평가). 대상: v5, 1280x720, 한국어.

## 원칙
- **미니멀. 빼기가 먼저.** 고칠 때 먼저 지우거나 합친다. 새로 더하는 것은 빼서는 안 될 때만.
- UI만 고친다. 규칙·밸런스·이야기·그림은 그대로 둔다.
- 순서대로 한다. 시간이 없으면 U1~U5까지.
- 끝나면 답장에 번호마다 "바꾼 것 한 줄 / 못 한 것"을 적는다.

## U1. 게임 바깥을 지운다
- 지울 것: 헤더 부제, 장소 줄, 큰 키 안내 줄, 아래 이야기 문구, 푸터. 같은 문구 반복("한 접시 두 개의 숟가락" ×2, "ONE MORE MEAL" ×2).
- 타이틀에 남길 것: 제목, 한 줄 소개, 시작 버튼.
- 게임 중에는 게임 화면만 창에 꽉 차게 보이고, 페이지가 스크롤되지 않게 한다.
- 완료: 1280x720에서 스크롤 없이 게임 화면 전체가 보인다.

## U2. HUD를 한 벌로
- 지울 것: 오른쪽 위 "돈·오늘의 식사" 묶음(아래와 중복). 그 자리는 비우거나 "밤까지 남은 시간"만 둔다.
- 남길 것: 돈, 식사, 들킨 횟수. 셋 다 같은 방식(아이콘 개수)으로 보여 준다. 지금 "들킨 횟수"만 글자로 "0 / 3"이다.
- 읽히게 할 것: HUD 글자가 밝은 그림 위에서 안 보인다. 글자를 줄이고 아이콘으로 바꾼 뒤, 남은 글자만 밝게·크게 한다.
- "연속 굶은 밤 0/2": 보일지 숨길지 파이가 정한다(아안: 배드엔딩 스포일러 / AI: 안 보이면 위험).
- 완료: 같은 정보가 두 번 나오지 않는다. 처음 보는 사람이 3초 안에 "몇 번 더 들키면 끝?"에 답한다.

## U3. 글을 줄인다
- 첫 대화: 해설 줄 "아이는 아빠가 일하러 가는 걸 알고 있습니다." 삭제. 버튼 "더 듣기" → "다음". 말풍선 꼬리가 말하는 아이를 가리키게 한다(지금은 빈자리).
- 튜토리얼 아래 잘린 문장 "…하기 전까지 거리는 멈춰 있어요."는 지운다. 필요하면 짧게 다시 쓴다.
- 소매치기 패널: 같은 뜻 문장 세 개(띠·부제·하단)를 하나로. 처음부터 보이게, 패널이 움직이지 않게. 제목 줄이 "주머 / 니"로 꺾이지 않게.
- 게임 화면 속 "손끝을 멈추지 마세요…"(간판과 겹침) 삭제.
- 일시정지의 "CHAPTER 01 / 잠시, 숨을 고르며. / 거리는 여기서 기다립니다…" 삭제.
- 하루 마감 표현을 하나로 통일한다(지금: 가게 문이 닫히기 전 / 밤이 오기까지 / 별이 뜨기 전 / 빛이 사라지기 전).
- 플레이 안내(1,528자)는 절반 이하로 줄인다. 가게 가격은 표 한 개로 만든다.
- 완료: 화면에서 같은 말이 두 번 나오지 않고, 보면 아는 내용을 다시 설명하는 문장이 없다.

## U4. 일시정지는 버튼만
- 첫 화면: [계속] [음량] [조작키] [안내]만 둔다. 조작키 표는 [조작키]를 눌러야 나온다(아안 지적).
- 완료: ESC를 누르면 스크롤 없이 [계속]이 보인다.

## U5. 키 이름을 하나로
- 같은 키를 화면마다 다르게 부른다(W 입장/가게 들어가기, F 숨기/웅크리기, E 소매치기/훔치기/상호작용/취소). 키마다 이름을 하나로 정해 모든 화면에서 쓴다.
- 소매치기 중 SPACE 규칙이 패널에 없다. 패널의 한 문장 안에 넣는다. 포기 키도 하나로 정한다(E와 A/D가 충돌).
- 완료: 모든 화면에서 같은 키를 같은 이름으로 부른다.

## U6. 분위기 (파이가 고른다)
- 아안: "UI는 진지한 명조체인데 플레이는 슬금슬금 으흐흐 얍 후다닥." 비네트(가장자리 어둡게)는 왜 있는지 모르겠다.
- 에이전트는 바꾸기 전에 파이에게 묻는다: 톤을 가볍게 맞출지, 지금 톤을 유지할지. 비네트를 지울지.
- 완료: 파이가 고른 방향이 답장에 있다.

## 재평가
수정이 끝나면 매니저가 같은 화면을 다시 캡처하고 같은 평가 에이전트로 U1~U6을 해결 / 일부 / 그대로 / 새 문제로 비교한다.
