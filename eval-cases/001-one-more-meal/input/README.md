# 입력 메모 — 한 끼의 무게 (One More Meal) v5

- 제작: 파이(AI로 제작). 기능만 계속 추가했고 UI 검수는 한 번도 하지 않음(아안 설명).
- 형식: 단일 HTML 웹 게임(game-v5.html, 22MB, 이미지 내장, git 제외). 매니저가 http://localhost:8765/game-v5.html 로 열어 1280x720 창(한국어 설정)에서 캡처했다. 스크린샷은 브라우저 축소 때문에 800px 폭이다. 작은 글자 판단은 아래 DOM 측정값을 우선한다.
- 장르: 2D 생존 사이드뷰. A·D 이동, W 가게 들어가기, E 소매치기, Q 썩은 음식 두고 가기, G 길게 눌러 버리기, F 엄폐물 뒤 웅크리기, M 집으로, SHIFT 달리기, ESC 일시정지(키 안내 기준).
- 제작 의도(아안 해석): 진지한 이야기. 플레이 감각은 가볍고 빠름(아안 메모: "UI는 진지한 명조체, 플레이는 슬금슬금 으흐흐 얍 케케케 후다닥").

## 화면
- s01 타이틀(위): 헤더, 장소 줄, 큰 제목, 시작 버튼
- s02 타이틀(아래로 스크롤): 키 안내 줄, 하단 문구, 푸터
- s03 첫 대화 1/3(아이 대사 상자, "더 듣기")
- s04 대화 3/3: 페이지가 자동으로 아래로 스크롤된 상태
- s05 1일째 시작: HUD 전체 + 조작 안내 상자

HUD 글자는 13~17px이고, 배경 판 없이 밝은 픽셀아트 배경 위에 직접 올라가 있다. 색은 rgb(150~190) 계열의 흐린 연두·베이지다. "돈"과 "오늘의 식사"가 오른쪽 위와 아래에 두 번 나온다.
- s06 걷기 튜토리얼 2단계("→ 사람이 가까이 올 때까지 오른쪽으로 걸어가세요.")
- s07 소매치기 튜토리얼("E 등 뒤에 섰어요. 멈춘 채로 E를 눌러 보세요.")
- s08 소매치기 패널이 처음 열린 모습. 맨 위 노란 안내 띠가 아직 안 보임. 제목 "행인 · 주머니"가 두 줄로 꺾임
- s09 지갑을 끌어 본 뒤: 노란 안내 띠("마우스로 지갑을 잡고 선을 따라 움직여 훔칠 수 있습니다.")가 나타나면서 패널이 아래로 밀림
- s10 ESC 일시정지·설정(위): 음량, 조작키 표
- s11 ESC 일시정지·설정(안을 스크롤): 맨 아래 "이야기로 돌아가기" 버튼은 스크롤해야 보임
- s12 플레이 안내: 글 1,528자, 21문단, 모달 안 높이 1758px 중 632px만 보임

## DOM 측정 추가
- s08/s09 소매치기 패널: 안내 띠 글자색 rgb(31,42,29) 17px. 첫 표시 때는 어두운 바탕 위라 안 보이다가 나중에 노란 띠가 생김. 부제 13px "지갑을 잡고 선을 따라 빼내세요. 머리 위에 ?가 뜨면 빨리 E! A / D 누르면 포기." 하단 15px "지갑을 클릭해서 꾹 잡으세요."
- 소매치기 중 HUD 전체 투명도 0.65. 패널 왼쪽 위 게임 화면 안에 "손끝을 멈추지 마세요. 누군가는 보고 있을 수 있습니다."(17px)가 간판 "빵집"과 겹쳐 표시됨
- 일시정지 메뉴: 조작키 안내 13px, 버튼 글자 14px
- 플레이 안내를 연 채로도 뒤의 소매치기 패널 DOM이 남아 있음
