# UI 평가 — 2048 (play2048.co) 첫 접속 화면 (BUILD, 2026-10-24)
메타: 숫자 합치기 퍼즐 / 웹(PC), 브라우저 캡처 800x600 / 입력: input/README.md, input/start-screen.jpg (1장) / 핵심 조작: 화면에서 확인 불가(일반적인 2048은 방향키·스와이프로 알려져 있으나 이 화면에는 안내 없음) / 제작 의도: unknown
판단 범위: 첫 접속 정지 화면의 배치·문구·버튼·가림만 볼 수 있었다. 조작 반응, 타일이 생긴 뒤의 화면, 점수 변화, 튜토리얼 내용, 아이콘 버튼 기능, 게임 오버 흐름, 소리는 볼 수 없었다.

## 관찰 (판단 전 목록)
- 상단: 왼쪽에 햄버거 메뉴(≡), 큰 갈색 제목 "2048", 오른쪽 끝에 "New Game" 버튼.
- 상단 가운데~오른쪽: 어두운 팝업 "WELCOME TO 2048! / Would you like to learn how to play?" + "Play Tutorial" 버튼 + 오른쪽 위 ✕ 닫기. 팝업 왼쪽 끝이 제목 "2048"의 오른쪽에 바짝 붙어 있다.
- 가운데: 4×4 판, 16칸 모두 비어 있음(숫자 타일 없음).
- 판 아래: 글자 없는 아이콘 버튼 3개(되돌리기 화살표, 바꾸기로 보이는 아이콘, 2×2 격자 아이콘). 각 버튼 아래에 짧은 막대 2개씩, 막대마다 진하기가 다름.
- 그 아래: 작은 연한 글씨 "play2048.co © 2014–2026 Gabriele Cirulli. All rights reserved."
- 맨 아래: 광고 배너(Adobe Firefly, 한국어). 판을 가리지는 않음.
- 점수·최고 점수 표시는 화면 어디에서도 보이지 않는다.
- 판과 아이콘 버튼 묶음이 화면 가운데(x≈400)보다 오른쪽(x≈536 중심)으로 치우쳐 있고, 왼쪽 1/3 정도가 비어 있다.

## 우선 고칠 것 (심각도 높은 순)

### F1. 판 아래 아이콘 버튼 3개의 뜻과 아래 막대의 뜻을 알 수 없다
- 위치: start-screen.jpg, 판 바로 아래 가운데 아이콘 버튼 3개와 그 아래 막대들
- 관찰: 버튼에 글자 라벨이 없다. 되돌리기 화살표는 짐작되지만 나머지 두 개(겹친 사각형+화살표, 2×2 격자)는 뜻이 화면에 없다. 각 버튼 아래 막대 2개는 진하기가 서로 다르지만 무엇을 세는지 설명이 없다(남은 사용 횟수일 가능성 — 가설).
- 기준: C09 조작 안내, C04 상태 전달
- 영향: 처음 온 플레이어가 버튼을 눌러 보기 전에는 기능을 모른다. 횟수 제한이 있는 기능이라면 모르고 써 버리거나, 반대로 아까워서 아예 안 쓸 수 있다.
- 심각도: 2 / 확신도: 중간 (마우스를 올리면 설명이 나올 수도 있는데 정지 화면이라 확인 못 함)
- 수정 제안: ① 아이콘 아래에 짧은 글자 라벨("되돌리기" 등)을 붙인다. ② 막대 대신 "남은 2회"처럼 숫자로 쓰거나, 막대 옆에 "남은 횟수" 설명을 단다. ③ 처음 한 번은 튜토리얼에서 이 세 버튼을 짚어 준다.
- 확인 방법: 2048을 처음 하는 친구에게 화면만 보여 주고 "이 세 버튼과 아래 줄은 각각 뭘 하는 것 같아?"라고 묻는다. 답이 실제 기능과 다르면 문제 확정.

### F2. 점수(목표 진행)가 첫 화면에서 보이지 않는다
- 위치: start-screen.jpg 전체 (특히 상단 제목~"New Game" 사이, 팝업이 덮은 영역)
- 관찰: "Score", "Best" 같은 점수 표시가 화면 어디에도 없다. 상단 팝업(제목 오른쪽~"New Game" 왼쪽)이 덮은 자리 밑에 있을 수도 있다.
- 기준: C04 상태 전달, C11 시야 확보
- 영향: 점수가 팝업 밑에 숨은 거라면 팝업이 상태 정보를 가리는 것이고, 원래 없는 거라면 플레이어가 자기 진행을 확인할 곳이 없다. 둘 중 어느 쪽인지는 이 이미지로 판단 불가.
- 심각도: 2 / 확신도: 낮음
- 수정 제안: ① 환영 팝업을 점수 자리와 겹치지 않는 곳(판 위 가운데 등)에 띄운다. ② 점수를 판 바로 위에 항상 보이게 둔다.
- 확인 방법: 팝업을 닫은 화면과 게임을 몇 수 둔 화면을 캡처해서 점수가 어디에 나타나는지 본다.

### F3. 첫 화면의 판이 비어 있어 "지금 시작된 건지" 알기 어렵다
- 위치: start-screen.jpg 가운데 4×4 판
- 관찰: 16칸이 모두 빈칸이다. 숫자 타일이 하나도 없고, "방향키를 눌러 시작" 같은 안내도 없다.
- 기준: C07 온보딩, C05 입력 피드백
- 영향: 튜토리얼을 닫은 플레이어가 무엇을 눌러야 시작되는지(New Game? 방향키?) 망설일 수 있다. 팝업을 닫으면 타일이 생기는 설계일 수도 있다(unknown).
- 심각도: 2 / 확신도: 낮음 (팝업 닫은 뒤 상태를 못 봤다)
- 수정 제안: ① 첫 화면부터 시작 타일 2개를 깔아 둔다. ② 빈 판이 의도라면 판 위에 "방향키(또는 스와이프)로 타일을 움직이세요" 한 줄을 띄운다.
- 확인 방법: 처음 하는 사람에게 팝업에서 ✕를 누르게 한 뒤 "이제 뭘 할 거야?"라고 묻고 첫 행동까지 걸리는 시간과 망설임을 본다.

### F4. 팝업 본문 글씨가 작다 (가독성 위험)
- 위치: start-screen.jpg 상단 팝업 왼쪽 "Would you like to learn how to play?"
- 관찰: 본문이 두 줄로 접힌 아주 작은 글씨이고, 제목 "WELCOME TO 2048!"도 작은 대문자다. 원본 800x600 캡처에서도 작게 보인다.
- 기준: C02 문자 가독성
- 영향: 첫 접속에서 튜토리얼을 권하는 유일한 문구인데 눈에 덜 띄어 그냥 ✕를 누르고 지나칠 수 있다.
- 심각도: 1 / 확신도: 중간 (대비비는 JPG라 원본 색값을 몰라 계산하지 않음)
- 수정 제안: 본문 글자를 "Play Tutorial" 버튼 글자와 같은 크기 이상으로 키우고, 한 줄로 줄인다("처음이세요? 30초 튜토리얼").
- 확인 방법: 화면에서 팔 길이만큼 떨어져 앉은 사람이 팝업 문구를 소리 내어 읽을 수 있는지 본다.

### F5. 화면 배치가 오른쪽으로 치우쳐 있고 상단이 붐빈다
- 위치: start-screen.jpg 판·아이콘 버튼 묶음(가운데보다 오른쪽), 상단 줄(≡, 2048, 팝업, New Game)
- 관찰: 판 중심이 화면 가운데보다 약 130px 오른쪽이고 왼쪽 영역이 비어 있다. 상단에서는 제목 "2048"과 팝업 왼쪽 끝이 거의 맞닿아 있다.
- 기준: C01 정보 위계, C11 시야 확보
- 영향: 기능 장애는 아니지만 시선이 판에서 시작하지 않고 흩어진다. 800x600 같은 작은 창에서만 생기는 배치일 수 있다.
- 심각도: 1 / 확신도: 낮음 (다른 창 크기를 보지 못함)
- 수정 제안: 작은 창에서는 판·제목·버튼을 한 세로줄 가운데로 모으고, 팝업은 제목과 겹치지 않게 아래로 내린다.
- 확인 방법: 같은 페이지를 800x600, 1280x720, 1920x1080에서 캡처해 판 위치를 비교한다.

## 플레이테스트 필요 (이번 입력으로 판단 불가)
- 조작 반응·손맛(C05, C06): 방향키/스와이프 뒤 타일 이동·합쳐짐 애니메이션, 반응 속도는 정지 화면으로 볼 수 없다. 짧은 플레이 영상(입력 순간이 보이게)이 필요.
- 타일 숫자 색 구분(C03, C08): 빈 판이라 숫자 타일 색과 글자 대비를 볼 수 없다. 몇 수 둔 화면 캡처 필요.
- 조작 안내(C09): 방향키 안내가 튜토리얼이나 다른 곳에 있는지 모름. "Play Tutorial"을 눌러 본 화면 필요.
- New Game 실수 방지(C10): 게임 도중 "New Game"을 누르면 확인을 묻는지 모름. 게임 중간에 눌러 보기.
- 게임 오버·2048 달성 화면(C17), 광고가 플레이 중 판을 가리는지(C11): 진행 화면이 필요.
- 소리·흔들림(C15): 정지 이미지로 판단 불가.

## 잘된 점 (근거 있는 것만)
- 첫 접속에 튜토리얼을 바로 권하고, 오른쪽 위 ✕로 쉽게 건너뛸 수 있다(C07 온보딩, C10 복구) — start-screen.jpg 상단 팝업.
- 4×4 판이 화면에서 가장 크고 진한 덩어리라 "여기가 놀이 공간"이라는 위계가 분명하다(C01) — 가운데 판.
- 광고 배너가 판·버튼 아래에 떨어져 있어 이 화면에서는 플레이 영역을 가리지 않는다(C11) — 하단 배너.
